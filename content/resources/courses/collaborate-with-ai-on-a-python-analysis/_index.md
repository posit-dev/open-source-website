<p>In this course, you learn how to use Posit Assistant, powered by an LLM, to augment each step of a Python data analysis. You will:</p>
<div>
<ol>
<li>Use Posit Assistant to generate and run Python code from a plain-language request</li>
<li>Use notebook-aware AI features (Notebook Assistant panel, one-click cell fixes, ghost cell suggestions) to iterate on an analysis</li>
<li>Convert an AI-assisted notebook into a Quarto report and reshape it into a dashboard</li>
<li>Publish a finished dashboard to Posit Connect</li>
</ol>
