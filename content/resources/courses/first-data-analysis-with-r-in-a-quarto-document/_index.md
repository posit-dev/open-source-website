<div>In this course, you learn how to set up Positron for a first R data analysis and explore a dataset in a Quarto document. You will:</div>
<br />
<ol>
<li>Install Positron and create a new R project from a template</li>
<li>Install the tidyverse package for data manipulation and visualization</li>
<li>Open a Quarto document and understand how it mixes markdown text and code cells</li>
<li>Explore a built-in dataset using the Variables pane and Data Explorer</li>
<li>Render a Quarto document into a shareable HTML report</li>
</ol>
