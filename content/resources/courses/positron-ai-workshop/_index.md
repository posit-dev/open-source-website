<p>Positron is a new multi-language code editor for data science. This workshop will introduce R and Python users to Positron, with an emphasis on Positron's innovative AI features. Students will:</p>
<ul>
<li>Take a tour of Positron that shows why it is well-suited for data science</li>
<li>Interact with Quarto documents, generate plots, and explore data with Positron&rsquo;s Data Explorer</li>
<li>Import, Clean, and Explore data with Posit Assistant</li>
<li>Write a summary report using Posit Assistant</li>
<li>Debug and write code with AI assistance</li>
<li>Learn Posit's data science-friendly philosophy for AI</li>
</ul>
<p>Participants will code in an environment provided by Posit that "just works" so students can experience the excitement of Positron with no installation, setup, or security issues.</p>
