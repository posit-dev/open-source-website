This cheat sheet is in Spanish. It covers the fundamental building blocks of R for beginners:
getting help, using packages, and working with R's main data structures including vectors,
matrices, data frames, and lists.

## What's covered
- Getting help – `?`, `help.search`, `help(package=...)`
- Data types overview – vectors, factors, matrices, arrays, lists, and data frames
- Using packages – `install.packages`, `library`, accessing package functions
- Vectors and factors – creating, selecting by position and value, `unique`, `sort`, `length`
- Matrices – `matrix`, selecting rows/columns/elements, `t` (transpose), `%*%` (multiplication)
- Data frames – `data.frame`, selecting columns and rows, `View`, `head`, `nrow`, `cbind`, `rbind`
- Lists – `list`, selecting by index, name, and `$`
- Working directory and assignment
