<p><a data-t="169">Now that you got how I interact with computer, let's talk about data science.</a> <a data-t="196">Data science involves a cycle of interaction with data, such as importing, tidying, transforming,</a> <a data-t="203">visualizing, and modeling.</a> <a data-t="206">And it feels like data science is highly vision-dominant.</a> <a data-t="209">Yes, it could be.</a></p>

<p><a data-t="213">But data science is more than what is seen.</a> <a data-t="219">If data science was restricted to only vision domain, that would mean that people who cannot</a> <a data-t="227">employ vision sense can't do data science at all.</a> <a data-t="233">Very fortunately, however, that is not true, because we have R, which enables blind people</a> <a data-t="241">see data beyond visual models.</a></p>

<p><a data-t="281">Second, the beautiful interplay between reproducibility and accessibility.</a> <a data-t="289">R Markdown is a plain text-based document for reproducible report that can be written</a> <a data-t="297">with any text editor and can be rendered into multiple formats, including HTML, Word, PDF,</a> <a data-t="306">EPUB, and more.</a> <a data-t="309">These outputs, in many cases, are made readily accessible to assistive technologies.</a> <a data-t="317">Especially, the HTML output is super accessible.</a></p>

<h3>Shiny accessibility improvements</h3>

<p><a data-t="866">I'm going to talk a little bit about Shiny.</a> <a data-t="871">I'm super excited to announce that Shiny is getting accessible.</a> <a data-t="876">With the amazing support of Winston, Carson, Barrett, and other Shiny team members, I was</a> <a data-t="883">working for making Shiny accessible for my internship activity at RStudio.</a> <a data-t="888">As a result, you will see many accessibility improvements in the next Shiny release, version</a> <a data-t="895">1.6 or higher.</a> <a data-t="899">If you want to test the development version, that's available on GitHub, and you can install</a> <a data-t="905">it through remote package.</a></p>

<p><a data-t="910">Some significant improvements are as follows.</a> <a data-t="914">First, we've added PayPal's bootstrap accessibility plugin under the hood.</a> <a data-t="922">So alert, tooltip, popover, model dialogue, dropdown, tab panel, collapse, and carousel</a> <a data-t="932">elements are made keyboard accessible.</a></p>

<p><a data-t="938">Next, there are many significant improvements made for Shiny widgets.</a> <a data-t="946">Select input, especially selectize input, file input are now fully keyboard accessible.</a> <a data-t="955">Font awesome and glyphic icon now produces appropriate labels based on icon names for</a> <a data-t="963">screen readers.</a> <a data-t="966">Media buttons and checkbox group input are properly grouped together for assistive technologies.</a> <a data-t="977">Date input and date range input are properly labeled.</a> <a data-t="985">And now dynamic contents within all the output and update input are auto announced to screen</a> <a data-t="993">readers and refreshable bread display.</a></p>

<p><a data-t="1001">There are also some great enhancements for semantic accessibility.</a> <a data-t="1007">We can pass alt text to render plot function to specify alternative text description for</a> <a data-t="1015">screen readers.</a> <a data-t="1018">It could be a static text.</a> <a data-t="1022">Not object is given by default.</a> <a data-t="1026">Or you can even use reactive function for alt term to create dynamic text that is useful</a> <a data-t="1034">when you want to create reactive alt text in response to user input.</a></p>

<p><a data-t="1042">And you can explicitly set the lang code, language code, used within your Shiny app</a> <a data-t="1052">by passing lang parameter to float page function.</a> <a data-t="1058">This helps search engine parsers and assistive tech better identify document language.</a> <a data-t="1067">Last but not least, semantic landmarks have been applied to main panel as well as sidebar</a> <a data-t="1074">panel for screen readers to quickly navigate through Shiny apps in a logical manner.</a></p>
