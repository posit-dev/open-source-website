description: 'Tidy data means one variable per column, one observation per row, and one value per cell. R is built around element-wise operations on columns, so data in that shape works with the language instead of against it. tidyr is the package that gets you there: gather turns columns into key and value pairs, spread turns key and value pairs back into columns, and unite and separate split or combine the values inside them.


  What you will learn

  - What tidy data is, in three rules you can check a dataset against

  - How to tell a tidy dataset from an untidy one, with worked examples of both

  - Why an untidy layout forces you to write worse code

  - What element-wise operations are, and why they reward a tidy layout

  - How gather works, and what key and value mean

  - How spread reverses it, and when you would want to

  - What unite and separate do to the values inside a column
