<h3>Quarto dashboards</h3>

<p><a data-t="1361">So Quarto dashboards are an HTML format</a> <a data-t="1365">designed for the full page layout of plots and tables and values.</a> <a data-t="1369">And this is one I found out out in the wild,</a> <a data-t="1371">somebody already using it</a> <a data-t="1373">for the Shelby County Department of Housing.</a> <a data-t="1377">The fundamental unit in a Quarto dashboard is a card.</a> <a data-t="1381">And these cards get laid out in rows and columns.</a></p>

<p><a data-t="1386">What does it look like to build a Quarto dashboard?</a> <a data-t="1388">Take a look at this HTML document.</a> <a data-t="1390">It's got a table, it's got a plot, it's got a map.</a> <a data-t="1395">What does it take to turn that into a dashboard?</a> <a data-t="1399">Well, you simply swap out format HTML for format dashboard.</a> <a data-t="1404">All of the computational outputs are going to get put into cards</a> <a data-t="1408">and then those cards get laid out on the page.</a></p>

<p><a data-t="1413">By default, that happens in a single column.</a> <a data-t="1414">You can see they're all stacked on top of each other.</a> <a data-t="1416">What happens if you want a two-row layout?</a> <a data-t="1419">All you have to do is add two markdown headings.</a> <a data-t="1423">It's as simple as that.</a></p>

<p><a data-t="1426">You can put anything in a Quarto dashboard</a> <a data-t="1428">that you could normally put in a Quarto document.</a> <a data-t="1431">But there are some specific dashboard components.</a> <a data-t="1434">So, for example, there are these value boxes.</a> <a data-t="1437">These are ways to have a single value</a> <a data-t="1440">but in a visually attractive way.</a> <a data-t="1442">And there is this idea of input panels,</a> <a data-t="1445">which is a way to group together interactive inputs</a> <a data-t="1448">into sidebars or toolbars.</a></p>

<p><a data-t="1452">You can also add interactivity in a Quarto dashboard</a> <a data-t="1455">any way you can in a Quarto document,</a> <a data-t="1458">including native support for observable JS.</a> <a data-t="1461">You can use frameworks like </a><a href="/software/leaflet/">Leaflet</a><a data-t="1461"> and Plotly and 3JS</a> <a data-t="1465">through HTML widgets in R and Jupyter widgets in Python.</a> <a data-t="1469">And, of course, you can use Shiny.</a> <a data-t="1471">You can add Shiny and </a><a href="/software/shiny-python/">Shiny for Python</a><a data-t="1471"> inputs</a> <a data-t="1475">and outputs directly in code cells.</a></p>

<h3>Quarto and the future of PDF</h3>

<p><a data-t="1540">The next thing I want to talk about is the future.</a> <a data-t="1543">The next thing I want to talk about</a> <a data-t="1545">comes from looking towards the future.</a> <a data-t="1548">In particular, the future of PDF.</a></p>

<p><a data-t="1552">Let me tell you about our PBC report.</a> <a data-t="1556">This is a report that Posit makes every two years</a> <a data-t="1558">that tracks our progress toward our mission.</a> <a data-t="1563">And it is primarily a PDF document.</a> <a data-t="1567">Here's the cover of that document.</a> <a data-t="1569">Inside, there's some pages</a> <a data-t="1571">that have this dark blue hex background.</a> <a data-t="1573">There's some pages that have a white background</a> <a data-t="1575">but with some full bleed photos.</a> <a data-t="1577">Text is laid out in two columns.</a> <a data-t="1579">Some pages have a banner at the top.</a> <a data-t="1581">There's plots in there.</a></p>

<p><a data-t="1584">This year, we made that report with Quarto.</a> <a data-t="1588">And if you've made PDFs with Quarto before,</a> <a data-t="1590">you know that they go through LaTeX on that journey.</a> <a data-t="1594">But we did not make this report by going through LaTeX.</a> <a data-t="1599">We used Typed.</a> <a data-t="1601">Typed is a new open source framework for producing PDFs.</a> <a data-t="1605">And it's already supported by Quarto.</a> <a data-t="1608">To use Typed, you simply swap out format PDF for format Typed.</a></p>

<p><a data-t="1615">We think Typed is the future of PDF</a> <a data-t="1617">because it's really easy to get started.</a> <a data-t="1620">Quarto bundles Typed,</a> <a data-t="1622">so there's no separate install to manage.</a> <a data-t="1625">You can do it today.</a> <a data-t="1629">Typed is really fast.</a> <a data-t="1630">So rendering a PDF via Typed</a> <a data-t="1633">is much faster than rendering a PDF via LaTeX.</a> <a data-t="1637">We think it's easier to learn.</a> <a data-t="1639">There's great documentation on the Typed site.</a> <a data-t="1642">And the syntax feels a lot more familiar</a> <a data-t="1644">to people that are coming from languages</a> <a data-t="1646">like R or Python or Julia.</a> <a data-t="1648">And it's very customizable.</a> <a data-t="1651">So our report being an example of that.</a> <a data-t="1653">It took a little work to get that customization,</a> <a data-t="1655">but you can produce really beautiful documents.</a></p>

<blockquote><a data-t="1615">We think Typed is the future of PDF</a> <a data-t="1617">because it's really easy to get started.</a></blockquote>

<p><a data-t="1660">So we think it's the future of PDF.</a> <a data-t="1661">It maybe isn't quite the present of PDF.</a> <a data-t="1664">Typed is still developing,</a> <a data-t="1665">and our support in Quarto is still developing too.</a> <a data-t="1669">But I do want to show you something really cool</a> <a data-t="1672">you can do in Typed right now.</a></p>

<p><a data-t="1675">So take a look at this table.</a> <a data-t="1676">This is an HTML table.</a> <a data-t="1678">It's built using the GreatTables package in Python.</a> <a data-t="1680">And an example from Grant Chalmers.</a> <a data-t="1683">It's on the GreatTables documentation site.</a> <a data-t="1687">And I think it's a beautiful table.</a></p>

<p><a data-t="1691">And GreatTables and </a><a href="/software/gt/">GT</a><a data-t="1691"> and a lot of table packages</a> <a data-t="1694">really focus on absolutely beautiful HTML output.</a> <a data-t="1698">So what happens if you switch to Typed?</a> <a data-t="1703">Well, behind the scenes,</a> <a data-t="1704">Quarto takes all the CSS</a> <a data-t="1706">that makes that HTML table really beautiful,</a> <a data-t="1709">and it converts it to Typed properties.</a> <a data-t="1713">And what that means is when you get your PDF out,</a> <a data-t="1716">that table looks just as good as it did in HTML,</a> <a data-t="1720">but now it's in a PDF.</a> <a data-t="1723">And not only that, like Typed is sort of good enough</a> <a data-t="1726">to know that, hey, this table's pretty long.</a> <a data-t="1728">It's not going to fit on one page.</a> <a data-t="1730">I'll break it over two pages,</a> <a data-t="1732">and I'll repeat the headers and footers</a> <a data-t="1733">and make it all just work for you.</a> <a data-t="1736">It's really cool.</a></p>

<h3>How WebAssembly works</h3>

<p><a data-t="1966">So how does this work?</a> <a data-t="1968">The main technology is called WebAssembly</a> <a data-t="1972">and what WebAssembly is,</a> <a data-t="1973">is a portable binary code format.</a> <a data-t="1975">So what does that mean?</a></p>

<p><a data-t="1978">Really this just means that</a> <a data-t="1979">if you take a piece of software and compile it,</a> <a data-t="1981">you get a big list of instructions to execute.</a> <a data-t="1984">The word portable here</a> <a data-t="1985">just means that those instructions,</a> <a data-t="1987">the binary is the same on every machine.</a> <a data-t="1990">And that's done by running that binary inside a web browser.</a> <a data-t="1993">It's really designed to run</a> <a data-t="1995">high performance applications in this way.</a></p>

<p><a data-t="1997">It does work with most modern web browsers on many devices.</a> <a data-t="2002">And one of the things it's really great at is security</a> <a data-t="2006">because it's really designed to run on the web.</a> <a data-t="2008">It runs your code in a containerized sandbox environment.</a> <a data-t="2011">In a web browser,</a> <a data-t="2014">you interact with WebAssembly through JavaScript</a> <a data-t="2017">and that has positives and negatives.</a></p>

<p><a data-t="2021">It means that WebR itself is a JavaScript application.</a> <a data-t="2024">So you need to write JavaScript to use it.</a> <a data-t="2027">And a positive of that is that</a> <a data-t="2029">it means it works great with other web technologies.</a> <a data-t="2032">A downside of that is that</a> <a data-t="2033">you probably don't love writing JavaScript code.</a> <a data-t="2036">At least not in the same way</a> <a data-t="2037">that the people in front of me love writing R code</a> <a data-t="2040">or they love writing Python code.</a></p>

<p><a data-t="2042">So for that reason,</a> <a data-t="2044">in addition to working on WebR,</a> <a data-t="2046">we produce tools built upon WebR to make your job easier.</a></p>

<h3><a href="/software/shinylive/">ShinyLive</a> and Quarto Live</h3>

<p><a data-t="2053">Tools like ShinyLive.</a> <a data-t="2055">At PositConf last year,</a> <a data-t="2057">Joe Tang had a talk introducing ShinyLive for R</a> <a data-t="2060">built upon the WebR technology.</a> <a data-t="2063">And over the years since then,</a> <a data-t="2065">we've been continuing to update the system.</a> <a data-t="2067">There's been several releases.</a> <a data-t="2069">And you can use ShinyLive now in a web browser</a> <a data-t="2073">to interact with live Shiny examples.</a> <a data-t="2076">You can export existing apps using an R package.</a></p>

<p><a data-t="2080">Or you can use a Quarto extension</a> <a data-t="2081">to embed Shiny applications</a> <a data-t="2083">directly into your Quarto documents.</a> <a data-t="2086">Again, the website example is great.</a> <a data-t="2088">You can go on to a URL and type some Shiny code</a> <a data-t="2091">and it just appears.</a> <a data-t="2093">And I've actually seen this used at workshops</a> <a data-t="2096">to teach people how to use Shiny</a> <a data-t="2097">and to share examples.</a></p>

<p><a data-t="2100">And that takes me on to one of the demographics</a> <a data-t="2104">that have really taken ShinyLive and run with it.</a> <a data-t="2106">And that's the demographic of educational content educators.</a> <a data-t="2110">They've really embraced the idea</a> <a data-t="2113">of WebAssembly-powered educational content.</a> <a data-t="2117">And for that reason,</a> <a data-t="2118">we thought to ourselves,</a> <a data-t="2119">well, is there more we can do?</a> <a data-t="2121">Can we get more WebAssembly into Quarto documents?</a></p>

<p><a data-t="2125">And the answer to that is yes.</a> <a data-t="2126">And I've been working on a new extension</a> <a data-t="2129">for Quarto over the last six months.</a></p>

<p><a data-t="2134">And we're calling it Quarto Live.</a> <a data-t="2136">Quarto Live is a way to get interactive code examples</a> <a data-t="2141">in R in your Quarto documents.</a> <a data-t="2144">You can directly interact with that code</a> <a data-t="2147">and you can create code exercises</a> <a data-t="2149">so that if you're an educator,</a> <a data-t="2151">you can create very easy ways</a> <a data-t="2153">for students to interact with your code</a> <a data-t="2156">and get quality feedback.</a></p>

<blockquote><a data-t="2136">Quarto Live is a way to get interactive code examples</a> <a data-t="2141">in R in your Quarto documents.</a> <a data-t="2144">You can directly interact with that code</a> <a data-t="2147">and you can create code exercises</a> <a data-t="2149">so that if you're an educator,</a> <a data-t="2151">you can create very easy ways</a> <a data-t="2153">for students to interact with your code</a> <a data-t="2156">and get quality feedback.</a></blockquote>

<p><a data-t="2160">We've designed Quarto Live to be really, really easy</a> <a data-t="2163">to use both for authors</a> <a data-t="2165">and for the students and learners.</a></p>

<p><a data-t="2168">So what does it look like?</a> <a data-t="2170">So let's say you have a Quarto document</a> <a data-t="2171">and it looks a bit like this.</a> <a data-t="2172">You've got some R code</a> <a data-t="2174">and it's producing a visualization.</a> <a data-t="2175">Here we have some </a><a href="/software/air/">air</a><a data-t="2175"> quality data</a> <a data-t="2177">from 1970s New York</a> <a data-t="2180">and it's plotting some temperatures</a> <a data-t="2181">and some ozone levels.</a></p>

<p><a data-t="2183">Now, let's say you want to turn this</a> <a data-t="2185">into an interactive example.</a> <a data-t="2186">Much like in Charlotte's examples,</a> <a data-t="2188">you change the format into a live format</a> <a data-t="2192">and you change your R block into a web R block.</a> <a data-t="2195">And if you have the Quarto Live extension installed,</a> <a data-t="2197">that's it.</a> <a data-t="2197">You do nothing else.</a> <a data-t="2198">It just, it works.</a></p>

<p><a data-t="2970">There's a lot here.</a> <a data-t="2971">Now, it's not difficult to unpack.</a> <a data-t="2973">All of us are capable</a> <a data-t="2974">of writing code like this.</a> <a data-t="2976">But there's a lot of detail here</a> <a data-t="2977">that just provides opportunities</a> <a data-t="2979">for mistakes.</a> <a data-t="2980">I need to know</a> <a data-t="2981">what the </a><a href="/software/odbc/">ODBC</a><a data-t="2981"> driver is called.</a> <a data-t="2982">I need to understand</a> <a data-t="2983">what these different arguments are.</a> <a data-t="2985">And perhaps most critically,</a> <a data-t="2986">I need to make sure</a> <a data-t="2987">that I'm accessing this</a> <a data-t="2988">in a secure way</a> <a data-t="2989">that meets the security requirements</a> <a data-t="2991">of my organization,</a> <a data-t="2992">whether that's through a username</a> <a data-t="2993">and password</a> <a data-t="2993">or more often than not,</a> <a data-t="2995">some form of a security token</a> <a data-t="2996">that I don't have to remember,</a> <a data-t="2998">but I have to keep</a> <a data-t="2999">in a super secret location</a> <a data-t="3000">and update every 30 days.</a></p>

<p><a data-t="3002">That can become a challenge.</a> <a data-t="3004">So we've worked hard</a> <a data-t="3005">over the past several months</a> <a data-t="3005">to take this amount of work</a> <a data-t="3007">and turn it into something</a> <a data-t="3008">that looks more like this.</a></p>

<p><a data-t="3010">This approach dramatically simplifies</a> <a data-t="3012">our ability to connect</a> <a data-t="3013">to external data sources.</a> <a data-t="3015">Because again,</a> <a data-t="3016">until we have access to the data,</a> <a data-t="3017">the real work hasn't really started yet.</a> <a data-t="3020">We've accomplished this</a> <a data-t="3021">in a couple of different ways.</a> <a data-t="3022">One is through our contributions</a> <a data-t="3024">to the open source ODBC R package</a> <a data-t="3026">with functions like Databricks.</a> <a data-t="3028">And there's also a function</a> <a data-t="3028">called Snowflake</a> <a data-t="3030">that facilitate easy connections</a> <a data-t="3031">to these external resources.</a> <a data-t="3033">These functions are part</a> <a data-t="3034">of the open source package</a> <a data-t="3035">and are available to anyone.</a></p>

<p><a data-t="3037">We've also made some adjustments</a> <a data-t="3038">on the Posit Workbench side</a> <a data-t="3040">to make it much easier for individuals</a> <a data-t="3042">to gain access</a> <a data-t="3043">to these backend data resources.</a></p>

<h3>Application deployment</h3>

<p><a data-t="3102">Okay, so I've got access to the data.</a> <a data-t="3104">Now I'm able to do what I want to do.</a> <a data-t="3105">I explore the data.</a> <a data-t="3106">I understand what it's teaching me.</a> <a data-t="3108">I finally arrive at something</a> <a data-t="3109">that I want to share.</a> <a data-t="3111">So what do I share?</a></p>

<p><a data-t="3113">In many cases,</a> <a data-t="3113">we see people share emails,</a> <a data-t="3115">PowerPoint presentations,</a> <a data-t="3116">static plots, documents.</a> <a data-t="3118">But more and more frequently,</a> <a data-t="3119">we're observing that users</a> <a data-t="3121">are creating dynamic dashboards</a> <a data-t="3123">and interactive web applications</a> <a data-t="3125">that allow end users</a> <a data-t="3126">and business users</a> <a data-t="3127">to discover, explore,</a> <a data-t="3128">and arrive at their own conclusions.</a></p>

<p><a data-t="3130">PositConnect makes it really easy</a> <a data-t="3132">to share and deploy</a> <a data-t="3133">these kinds of applications</a> <a data-t="3134">across your organization.</a> <a data-t="3135">So I can build a dashboard</a> <a data-t="3137">that I share with the rest of my company.</a></p>

<p><a data-t="3139">However, as soon as I make this transition</a> <a data-t="3141">from saying I've built something</a> <a data-t="3143">to I want to share something,</a> <a data-t="3144">I once again have to think</a> <a data-t="3145">about authentication.</a> <a data-t="3147">And the problem has gotten bigger</a> <a data-t="3148">because now I'm not just thinking</a> <a data-t="3149">about my own authentication</a> <a data-t="3150">and how do I access the data.</a> <a data-t="3152">Now I'm thinking about</a> <a data-t="3153">how should everyone</a> <a data-t="3154">who visits this application</a> <a data-t="3156">access the data.</a></p>

<p><a data-t="3158">In a world where data security</a> <a data-t="3160">is of highest importance,</a> <a data-t="3162">the last thing I want to do</a> <a data-t="3163">is unintentionally publish</a> <a data-t="3165">an application</a> <a data-t="3166">that gives someone else</a> <a data-t="3167">unauthorized access</a> <a data-t="3168">to data they should not</a> <a data-t="3169">otherwise be able to see.</a></p>

<p><a data-t="3171">Now, this is not a new problem necessarily.</a> <a data-t="3174">In fact, there are well-established</a> <a data-t="3175">patterns for how to approach this.</a> <a data-t="3176">One of them is to use</a> <a data-t="3177">some sort of access token</a> <a data-t="3178">attached to a service account.</a> <a data-t="3180">So I create some sort of account</a> <a data-t="3181">inside of Databricks, for example,</a> <a data-t="3183">or Snowflake.</a> <a data-t="3184">I say here's the permissions</a> <a data-t="3185">for that account.</a> <a data-t="3186">I generate a token</a> <a data-t="3187">and then I input that</a> <a data-t="3187">into my Connect product,</a> <a data-t="3189">into my dashboard</a> <a data-t="3190">so that it will use</a> <a data-t="3191">that same credential set</a> <a data-t="3192">whenever somebody</a> <a data-t="3193">visits the application.</a></p>

<p><a data-t="3195">This pattern works very well,</a> <a data-t="3197">but it really has</a> <a data-t="3198">two distinct limitations.</a> <a data-t="3199">One is everybody</a> <a data-t="3201">visiting this dashboard</a> <a data-t="3202">will see the same data</a> <a data-t="3203">regardless of what</a> <a data-t="3205">their specific permission set is.</a> <a data-t="3207">They will see data governed by</a> <a data-t="3209">the permission set</a> <a data-t="3210">of the service account I've set up.</a></p>

<p><a data-t="3212">The other problem though</a> <a data-t="3213">is that if the number of applications</a> <a data-t="3215">I build grows,</a> <a data-t="3217">the amount of service accounts</a> <a data-t="3219">and access tokens</a> <a data-t="3220">I'm responsible for also grows.</a> <a data-t="3222">And now I'm spending</a> <a data-t="3223">far more time</a> <a data-t="3224">worrying about data access</a> <a data-t="3225">and security from my</a> <a data-t="3226">deployed applications</a> <a data-t="3227">than I am building</a> <a data-t="3228">and distributing</a> <a data-t="3229">and creating new applications.</a></p>

<p><a data-t="3232">We're excited to announce</a> <a data-t="3233">that starting last week,</a> <a data-t="3235">this is all gone.</a> <a data-t="3236">What we've now introduced</a> <a data-t="3238">in Posit Connect</a> <a data-t="3238">is native support</a> <a data-t="3239">for authentication</a> <a data-t="3240">into Databricks and Snowflake</a> <a data-t="3241">just like we have</a> <a data-t="3242">in Posit Workbench.</a></p>

<blockquote><a data-t="3232">We're excited to announce</a> <a data-t="3233">that starting last week,</a> <a data-t="3235">this is all gone.</a> <a data-t="3236">What we've now introduced</a> <a data-t="3238">in Posit Connect</a> <a data-t="3238">is native support</a> <a data-t="3239">for authentication</a> <a data-t="3240">into Databricks and Snowflake</a> <a data-t="3241">just like we have</a> <a data-t="3242">in Posit Workbench.</a></blockquote>

<p><a data-t="3243">What this means is now</a> <a data-t="3244">instead of configuring</a> <a data-t="3245">an access token,</a> <a data-t="3246">I can come into Posit Connect</a> <a data-t="3248">and specify that</a> <a data-t="3249">I want to make sure that</a> <a data-t="3251">whoever visits this application</a> <a data-t="3253">signs in to their Databricks</a> <a data-t="3255">or Snowflake account.</a></p>

<p><a data-t="3256">Then as a viewer,</a> <a data-t="3258">if I come to the application,</a> <a data-t="3259">I'll see something like this.</a> <a data-t="3260">This is my view.</a> <a data-t="3262">But if I send this</a> <a data-t="3263">to somebody else</a> <a data-t="3263">and say I want you to log</a> <a data-t="3264">into this application,</a> <a data-t="3266">they'll first be prompted</a> <a data-t="3267">to log into their</a> <a data-t="3267">Snowflake account.</a> <a data-t="3269">And once they've logged</a> <a data-t="3269">in their Snowflake account,</a> <a data-t="3271">they'll see the same application</a> <a data-t="3272">but with their own unique view</a> <a data-t="3274">powered by the permissions</a> <a data-t="3275">they've been assigned</a> <a data-t="3276">inside of Snowflake.</a></p>

<p><a data-t="3278">This means I don't have to worry</a> <a data-t="3279">about who has access</a> <a data-t="3280">to what data.</a> <a data-t="3281">Instead, I can build something</a> <a data-t="3283">and share it</a> <a data-t="3284">and then anyone who accesses it</a> <a data-t="3285">will have access to the data</a> <a data-t="3286">they should be able to see</a> <a data-t="3288">based on the permission</a> <a data-t="3289">that have been set</a> <a data-t="3289">within the database.</a> <a data-t="3291">This works today for Snowflake</a> <a data-t="3292">and Databricks</a> <a data-t="3293">and we're actually looking</a> <a data-t="3294">at other ways that we can continue</a> <a data-t="3295">to expand this functionality.</a></p>
