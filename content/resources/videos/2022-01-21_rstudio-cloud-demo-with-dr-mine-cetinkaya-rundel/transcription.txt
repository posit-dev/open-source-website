<p><a data-t="1038">So this idea of sharing an RStudio cloud project</a> <a data-t="1041">on the plus side is super easy.</a> <a data-t="1044">First of all, I created my project</a> <a data-t="1046">and all I had to do was to flip a switch for shareability</a> <a data-t="1049">and share the URL.</a> <a data-t="1051">Other pluses associated with it</a> <a data-t="1053">is that students land directly in a project upon login.</a> <a data-t="1057">So, you know, we're telling them we're teaching RStudio</a> <a data-t="1059">and we give them a URL and they're right there.</a> <a data-t="1062">There's no additional steps they need to do.</a></p>

<p><a data-t="1064">I find that beyond teaching,</a> <a data-t="1067">this sort of sharing a project</a> <a data-t="1069">is actually great for just collaboration,</a> <a data-t="1073">particularly if I have collaborators</a> <a data-t="1075">with whom I want to share my code,</a> <a data-t="1077">but maybe they're not, you know, Git or GitHub users.</a> <a data-t="1080">So that's not the path we want to go</a> <a data-t="1082">or to create some reproducible examples</a> <a data-t="1085">that might be a bit more, you know,</a> <a data-t="1089">a bit more extensive than like a little snippet</a> <a data-t="1093">you might share with somebody on Slack or GitHub.</a> <a data-t="1097">So oftentimes if I'm trying to debug,</a> <a data-t="1099">for example, an extensive Shiny app,</a> <a data-t="1102">even if I make it pretty minimal,</a> <a data-t="1104">I find that there's a lot of code there</a> <a data-t="1106">to just post into a message.</a> <a data-t="1108">So often I'll create a single RStudio cloud project</a> <a data-t="1111">and then it ends up having the packages</a> <a data-t="1114">that I have installed ready to go as well</a> <a data-t="1116">to share with somebody else to ask a question.</a></p>

<p><a data-t="1119">Now on the negative side,</a> <a data-t="1121">that temporary copy thing with even with the handy</a> <a data-t="1125">save a permanent copy button next to it</a> <a data-t="1128">can sometimes get students because they need to remember</a> <a data-t="1131">to make a permanent copy of the project,</a> <a data-t="1134">which honestly, as an instructor to you</a> <a data-t="1137">means you need to remind them to do so.</a> <a data-t="1140">Otherwise their work can get lost.</a></p>

<p><a data-t="1163">The permanent other things that could be a plus or a minus,</a> <a data-t="1167">depending on your situation is that these permanent projects</a> <a data-t="1171">once the student makes the permanent project,</a> <a data-t="1172">they count towards their student's free account.</a> <a data-t="1175">So if you're an instructor who is not wanting</a> <a data-t="1178">to kind of use up your account's usage,</a> <a data-t="1182">that might be a plus.</a> <a data-t="1183">But if you're an instructor who is thinking,</a> <a data-t="1185">I would like to make sure that I'm offering this</a> <a data-t="1188">to my students for free forever,</a> <a data-t="1191">this may not be the right setup for you.</a></p>

<p><a data-t="1193">Also students control permissions on their project.</a> <a data-t="1196">This can also be a pro or a con.</a> <a data-t="1200">It's nice for them to have this control,</a> <a data-t="1202">but that might also mean that they are sharing it</a> <a data-t="1205">very liberally.</a> <a data-t="1206">So if you're teaching in a setting where,</a> <a data-t="1210">things like maybe giving an assignment</a> <a data-t="1214">that students should not be collaborating on in any way,</a> <a data-t="1217">should not see each other's code,</a> <a data-t="1219">this might make it easier for them to do something</a> <a data-t="1222">that they're not supposed to do.</a></p>

<h3>Tips for using RStudio Cloud effectively</h3>

<p><a data-t="1855">So now that we've talked a little bit</a> <a data-t="1857">about how to get students into your RStudio Cloud space</a> <a data-t="1861">and how to share your materials with them,</a> <a data-t="1864">I'll kind of try to wrap things up,</a> <a data-t="1866">but with some tips before we perhaps move</a> <a data-t="1869">into a bit of a Q and A.</a></p>

<p><a data-t="1872">So the first tip that I would mention</a> <a data-t="1875">is that changes to an assignment that you make,</a> <a data-t="1879">that after a student has started,</a> <a data-t="1881">won't propagate to their copy.</a> <a data-t="1883">So this is not like Google Docs in a way,</a> <a data-t="1886">is I think the best way to describe it.</a> <a data-t="1888">When your student makes a copy of a project</a> <a data-t="1890">you have set up for them</a> <a data-t="1892">in either of the sharing approaches,</a> <a data-t="1894">they're really taking a snapshot at that time.</a></p>

<p><a data-t="1897">So if you need to change your assignment,</a> <a data-t="1899">and I'm sure we've all been there,</a> <a data-t="1901">you assign a homework assignment,</a> <a data-t="1902">then you realize something is wrong.</a> <a data-t="1904">You're gonna need to get that information</a> <a data-t="1905">to them in another way,</a> <a data-t="1907">or have them start with a new project,</a> <a data-t="1909">or have your projects be linked to a Git repository as well.</a> <a data-t="1914">And you can change that Git repository</a> <a data-t="1915">and ask your students to pull the changes in.</a></p>

<p><a data-t="1919">Packages in the base project are installed, but not loaded.</a> <a data-t="1922">So when you're writing your instructions,</a> <a data-t="1925">you want to remind yourself,</a> <a data-t="1927">remind your students to do library, whatever package name,</a> <a data-t="1931">because they won't be able to use it immediately</a> <a data-t="1933">in the console.</a></p>

<p><a data-t="1937">This information is always on the RStudio Cloud guide</a> <a data-t="1941">and the What's New page.</a> <a data-t="1942">RStudio Cloud is still evolving.</a> <a data-t="1945">It is not changing in terms of,</a> <a data-t="1950">it's not changing in terms of like,</a> <a data-t="1951">in a way where it's going to be a completely different UI</a> <a data-t="1955">the next day your students land in it,</a> <a data-t="1957">but there are new features being added.</a> <a data-t="1960">And so it's nice to keep up with those.</a> <a data-t="1963">And if you encounter any sort of slowness or glitches,</a> <a data-t="1966">say your students are reporting, we can't log on,</a> <a data-t="1969">there's a current system status link on the side</a> <a data-t="1972">that's super handy.</a> <a data-t="1973">It allows you to check to see if there are real outage,</a> <a data-t="1976">and if not, you can go ahead and report it.</a></p>
