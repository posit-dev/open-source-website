<h3>Hard skills and soft skills of tools</h3>

<h3>Knowing your users</h3>

<p><a data-t="1162">So when we think about the soft skills, I really</a> <a data-t="1164">want people to think about the human side of a tool.</a> <a data-t="1168">And the first thing is to know your users.</a> <a data-t="1174">At Posit, a lot of us were data scientists.</a> <a data-t="1176">So we have a lot of data science knowledge.</a> <a data-t="1178">So we really intimately know the struggles of what we were running into.</a> <a data-t="1184">And I think something interesting here is</a> <a data-t="1187">the difference between a data scientist and a software engineer.</a> <a data-t="1190">Data work inherently looks a little bit different</a> <a data-t="1193">than what we would consider software engineer work.</a> <a data-t="1196">Data practitioners are more on exploring uncharted territories.</a> <a data-t="1201">They do a lot of iteration and a lot of experimentation.</a> <a data-t="1206">And then software engineers, we can think of them as building castles</a> <a data-t="1209">in known lands, things that involve a lot of structure,</a> <a data-t="1214">and things that have a very specific outcome.</a> <a data-t="1218">So you're not going to give your cartographer a mason's tools.</a> <a data-t="1222">So knowing your users is really important.</a> <a data-t="1224">And if you don't know, it's OK to ask.</a> <a data-t="1226">I think that's a very thoughtful way to approach this problem.</a></p>

<h3>Discoverability</h3>

<p><a data-t="1332">And discoverability is a lot of this work.</a> <a data-t="1335">So when you're thinking about sharing a report</a> <a data-t="1338">or thinking about building a tool, you want to really be this little goose</a> <a data-t="1343">that's shining your lantern on the path that should be traveled the most.</a> <a data-t="1347">This is really kind of a subset of knowing your user.</a> <a data-t="1351">And all of these soft skills really come from a place of empathy</a> <a data-t="1354">for the people who are using the tools that you're building,</a> <a data-t="1357">or thinking about how you want your tool to be used.</a> <a data-t="1360">How you want your tool to support you as you're using it.</a></p>
