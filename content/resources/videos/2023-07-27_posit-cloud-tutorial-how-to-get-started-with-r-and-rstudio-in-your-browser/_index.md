description: 'Posit Cloud runs RStudio in your browser. There is nothing to install and nothing to configure: you sign up, open a project, and you have a working R environment on any machine with a browser. This walkthrough sets up a free account, creates a workspace, saves a database connection, builds a project and a Shiny app against it, publishes the app, adds a collaborator and looks at the usage analytics. With Alex Chisholm, the product manager for Posit Cloud.


  What you will learn

  - What Posit Cloud is, and when it beats installing R locally

  - How to create a free account and open your first project

  - What a workspace is, and how it differs from a project

  - How to save a database connection so every project in a space can use it

  - How to build a Shiny app that reads from that connection

  - How to publish content, and what your audience sees

  - How to add collaborators and set what they can do

  - What the usage analytics tell you about who is using your work
