<h3>Why change was needed</h3>

<p><a data-t="115">So why do we need to change?</a> <a data-t="119">Maybe a third of you will recognise this thing.</a> <a data-t="122">This is a floppy disk that holds about one meg worth of data.</a> <a data-t="126">So historically, 10, 20 years ago when we were doing a farm trial,</a> <a data-t="132">we'd get a few observations per day.</a> <a data-t="135">So you could have a major trial where all the data would fit</a> <a data-t="139">on about six of these floppy disks.</a></p>

<p><a data-t="142">However, today we have wearable devices.</a> <a data-t="145">You can imagine Apple Watches for cows.</a> <a data-t="148">Devices like this are generating 60 observations a second</a> <a data-t="153">and you're putting this across hundreds and sometimes thousands of cows</a> <a data-t="159">and that's generating a metric crap tonne of data.</a></p>

<p><a data-t="164">And so if you put all the data for a three-month trial today onto floppy disks,</a> <a data-t="170">the tower of floppy disks would be taller than the Burj Khalifa,</a> <a data-t="173">like the tallest building in the world.</a></p>

<p><a data-t="177">Also at the same time, we had to move from linear science</a> <a data-t="183">in the sense of scientists would have an experiment,</a> <a data-t="187">they'd run the experiment, they'd throw some data at the statistician,</a> <a data-t="191">produce some plots and some tables, publish it, job done.</a> <a data-t="195">But when we're looking at this more complex data,</a> <a data-t="198">it becomes more iterative in the sense of looking at the data,</a> <a data-t="201">understanding what it's trying to tell us,</a> <a data-t="203">come up with some hypotheses, test those.</a> <a data-t="206">So a very different way of working.</a></p>

<p><a data-t="209">So these are not all the reasons,</a> <a data-t="211">but these were a couple of the obvious reasons that created</a> <a data-t="214">that burning platform for why we needed to do something different.</a></p>

<h3>Infrastructure</h3>

<p><a data-t="219">So we did three things.</a> <a data-t="222">The first thing was around infrastructure.</a> <a data-t="225">So if you've opened the R for Data Science book,</a> <a data-t="228">this diagram's probably quite familiar.</a> <a data-t="230">Anyone that's got R can get started and use this workflow.</a> <a data-t="234">But when you want to work at scale, you want to add a few things.</a></p>

<p><a data-t="238">So for us, we've got a data platform.</a> <a data-t="241">We chose Snowflake.</a> <a data-t="243">You might choose Databricks or something else.</a> <a data-t="245">For sharing code and versioning code, we use GitHub.</a> <a data-t="249">Again, there's other options there.</a> <a data-t="252">When the smoke is starting to pour out of your laptop,</a> <a data-t="255">it's time to move that compute to the cloud.</a> <a data-t="257">So we use Posit Workbench for that.</a> <a data-t="260">And then when we've created artifacts, tools, dashboards, et cetera,</a> <a data-t="263">that we want to share, then we push that through to Posit Connect.</a></p>

<p><a data-t="269">So what guided some of those choices?</a> <a data-t="271">Well, it needed to be fit for purpose,</a> <a data-t="273">and for us, that meant performance.</a> <a data-t="275">It needed to be scalable,</a> <a data-t="277">as we did more and more of this type of work,</a> <a data-t="280">and reproducible is just really good practice.</a> <a data-t="283">Also, we're starting from a low base,</a> <a data-t="286">so we want a relatively low cost to start.</a> <a data-t="289">So some open-source tools fit the bill there.</a> <a data-t="292">And you also need ease of management by your IT.</a> <a data-t="297">So that forms part of your total cost of ownership.</a></p>

<p><a data-t="304">You're going to need some confidence in the vendor,</a> <a data-t="308">but you also want to limit the technological lock-in</a> <a data-t="311">wherever possible, so you have options down the future.</a> <a data-t="314">You know, the landscape might change.</a> <a data-t="317">For us, support for R and Python,</a> <a data-t="320">we're primarily R now, but I could see there are some things</a> <a data-t="323">we might want to use Python for in the future,</a> <a data-t="326">and depending on where you're at and what your situation is,</a> <a data-t="329">you might make different choices.</a></p>

<p><a data-t="333">And so this involves spending money,</a> <a data-t="337">so you're going to need some allies from around the organization,</a> <a data-t="340">extra points if you get IT on board,</a> <a data-t="343">and then you're going to have to get the senior buy-in.</a> <a data-t="346">They're the people that are going to be writing the checks</a> <a data-t="348">for some of this stuff.</a></p>

<h3>Skills and capability</h3>

<p><a data-t="351">So the second of three things, the skills and capability.</a> <a data-t="355">So when we were starting down this journey,</a> <a data-t="358">we ran R for data science as an internal course.</a> <a data-t="363">We ran it as a cohort, so a bunch of people</a> <a data-t="366">all learning at the same time,</a> <a data-t="369">and the temptation is whenever you're doing something</a> <a data-t="372">in that setting that you try and just jam it all into,</a> <a data-t="375">like, say, three days.</a> <a data-t="377">We'll bring everyone in, smash them full of knowledge,</a> <a data-t="379">and then job done.</a></p>

<p><a data-t="381">But I took from the, what was the </a><a href="/software/rstudio/">RStudio</a><a data-t="381"> education piece</a> <a data-t="386">that they used to have around the space learning,</a> <a data-t="389">which is to say, you know, if you learn a bit this week,</a> <a data-t="392">then you've got time to digest it and use it,</a> <a data-t="395">and then more the next week, et cetera.</a> <a data-t="397">So that space learning as a concept, I think, is quite useful.</a></p>

<p><a data-t="404">You know, there was a few pros and cons to running it externally,</a> <a data-t="407">and we decided to go external for subsequent versions</a> <a data-t="411">and ran it through the university.</a> <a data-t="414">The things I like about doing it externally</a> <a data-t="416">is that you're getting some commitment</a> <a data-t="418">from both the person and the manager.</a> <a data-t="421">Even though it doesn't cost a lot,</a> <a data-t="423">you know, the fact that it actually costs something</a> <a data-t="425">means that that person and manager have to have a discussion</a> <a data-t="428">and they have to agree that this is a priority for this person,</a> <a data-t="432">and that means putting aside time to do it properly,</a> <a data-t="435">which is not necessarily what happened</a> <a data-t="438">when we had an internal course.</a> <a data-t="440">And if people got busy, then if it wasn't a priority,</a> <a data-t="443">it didn't happen.</a></p>

<p><a data-t="445">I also like the summative assessment,</a> <a data-t="447">so assessment at the end of the course,</a> <a data-t="449">which is to say, you know, people understand,</a> <a data-t="452">you know, most of these people have been to university,</a> <a data-t="454">so they understand that, you know,</a> <a data-t="456">there's going to be a test at the end</a> <a data-t="458">and they're going to have to have some minimum level of knowledge</a> <a data-t="461">in order to pass that and not be embarrassed in front of their peers.</a> <a data-t="465">So I like that.</a></p>
