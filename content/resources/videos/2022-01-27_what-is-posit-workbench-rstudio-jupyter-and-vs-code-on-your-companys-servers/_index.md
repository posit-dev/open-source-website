description: 'Posit Workbench is Posit''s server platform for data science teams. It lets people open RStudio, JupyterLab, Jupyter Notebooks or VS Code in a browser, running on infrastructure your IT team manages, with shared projects, pre-configured data connectors and controlled compute. Posit Workbench was previously called RStudio Workbench, and before that RStudio Server Pro.


  What you will learn

  - What problem Workbench solves: work spread across laptops and separate systems

  - Which editors it runs, and why supporting all four matters for a mixed R and Python team

  - How shared projects and real-time collaboration change code review

  - What pre-configured data connectors do, with Snowflake, MongoDB and Spark as examples

  - How compute requests work, and how user and group profiles control cost

  - How a standardised software set makes work reproducible between team members

  - How Git integration supports code governance

  A note on naming

  This video says RStudio Workbench. The product is now Posit Workbench. It was called RStudio Server Pro before that. It is the same product, and open-source RStudio Server is the free single-editor version.
