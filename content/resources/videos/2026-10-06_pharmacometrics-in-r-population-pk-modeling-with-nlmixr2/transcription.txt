<h3>The dosing question</h3>

<p><a data-t="63">Let's start with a question.</a> <a data-t="63">Preterm infants are prone to seizures and phenobarbital is</a> <a data-t="70">used to treat them.</a> <a data-t="70">The dose makes the poison.</a> <a data-t="70">Too little and the seizures continue.</a> <a data-t="70">Too</a> <a data-t="76">much and the baby can stop breathing.</a> <a data-t="76">A doctor read that one flat dose might work for every</a> <a data-t="82">neonate.</a> <a data-t="82">That would make giving the drug much simpler, but a flat dose tuned for an average</a> <a data-t="88">one and a half kilogram baby might not suit our 900 gram baby.</a> <a data-t="88">And we don't know where</a> <a data-t="93">that baby would land.</a></p>

<p><a data-t="97">The usual way to check exposure is to take blood samples and measure the drug level.</a> <a data-t="102">But a preterm baby has less than a teacup of blood in its whole body.</a> <a data-t="102">So a study with</a> <a data-t="106">15 samples per baby isn't possible.</a> <a data-t="106">What we have is scraps.</a> <a data-t="106">One sample here, another three</a> <a data-t="112">days later.</a> <a data-t="112">So we need a model that learns how weight affects drug clearance from earlier</a> <a data-t="117">data and then simulates the dose instead.</a></p>

<h3>What a pharmacometric model is</h3>

<p><a data-t="122">So what is a pharmacometric model?</a> <a data-t="122">If you fit a mixed model before, you've done half</a> <a data-t="129">of this already.</a> <a data-t="129">The difference is the mean function.</a> <a data-t="129">It isn't a line or a spline.</a> <a data-t="129">It's</a> <a data-t="133">the solution to a differential equation.</a> <a data-t="133">Think of a bucket with a hole in it.</a> <a data-t="133">Drug goes in</a> <a data-t="139">with the dose.</a> <a data-t="139">The volume is how widely the drug spreads and clearance is how fast it</a> <a data-t="144">drains out.</a> <a data-t="144">An L-mixer to that bucket is one line of ODE.</a> <a data-t="144">Each infant gets their own clearance.</a> <a data-t="151">The typical value plus their own random deviation.</a></p>

<p><a data-t="157">Models like this don't just fit a curve.</a> <a data-t="157">Their parameters mean something.</a> <a data-t="157">The loading dose,</a> <a data-t="162">the first big dose, is set by volume.</a> <a data-t="162">It's how much drug it takes to fill the bucket.</a> <a data-t="167">The maintenance doses are set by clearance.</a> <a data-t="167">They replace what drains out.</a> <a data-t="167">Because the</a> <a data-t="171">model separates the two, it can design a whole dosing regimen.</a> <a data-t="171">It can also predict doses</a> <a data-t="176">nobody in the study actually got.</a> <a data-t="176">That's why drug labels and pediatric doses are so</a> <a data-t="181">often built from models like this.</a></p>

<blockquote><a data-t="171">It can also predict doses</a> <a data-t="176">nobody in the study actually got.</a> <a data-t="176">That's why drug labels and pediatric doses are so</a> <a data-t="181">often built from models like this.</a></blockquote>

<h3>The sparse data</h3>

<p><a data-t="186">Now let's look at the data.</a> <a data-t="186">The data are 59 preterm infants given phenobarbital published</a> <a data-t="194">in 1985.</a> <a data-t="194">They ship with nlmixr2 as pheno underscore SD.</a> <a data-t="194">Each row in this plot is one</a> <a data-t="201">infant sorted by weight.</a> <a data-t="201">The small ticks are doses and the circles are measured concentrations.</a> <a data-t="208">There are 589 doses but only 155 measurements.</a> <a data-t="208">The babies were dosed often and sampled rarely</a> <a data-t="214">during routine care.</a></p>

<p><a data-t="218">Look closer and it gets worse.</a> <a data-t="218">Nine infants have exactly one concentration.</a> <a data-t="218">Forty percent</a> <a data-t="223">have two or fewer.</a> <a data-t="223">You can't estimate two parameters for a baby from one data point</a> <a data-t="228">unless, that is, you let the infants borrow strength from each other.</a> <a data-t="228">That's exactly what</a> <a data-t="233">the mixed effects model does.</a></p>

<h3>Building the model in nlmixr2</h3>

<p><a data-t="237">Let's build the model in nlmixr2.</a> <a data-t="237">The model is an ordinary R function with two blocks.</a> <a data-t="245">In the INI block, an arrow sets a fixed effect and a wavy single line sets a random effect.</a> <a data-t="251">The model block holds the differential equation written the way you'd write it on paper.</a> <a data-t="251">The</a> <a data-t="256">last line connects the prediction to the observed data with a proportional error.</a> <a data-t="256">Notice</a> <a data-t="261">there's no dosing in the model.</a> <a data-t="261">Doses come from the data.</a> <a data-t="261">The rest is plain R and one</a> <a data-t="266">called nlmixr2 fits it.</a> <a data-t="266">The base model gives 37 percent between infant variability</a> <a data-t="274">on clearance and 47 percent on volume.</a> <a data-t="274">That means two infants on the same dose can easily</a> <a data-t="280">differ twofold in exposure.</a> <a data-t="280">That's why a flat dose is risky.</a> <a data-t="280">These babies range from</a> <a data-t="285">0.6 to 3.6 kilograms.</a> <a data-t="285">When we add body weight with standard allometric scaling, variability</a> <a data-t="292">falls to about 17 and 18 percent.</a> <a data-t="292">The objective function drops by about 144 points.</a> <a data-t="292">More than</a> <a data-t="299">half of the variability is just body weight.</a></p>

<p><a data-t="304">We didn't have to rewrite the model to add weight.</a> <a data-t="304">With model piping, we swap the clearance</a> <a data-t="310">the volume line and set the two new initial estimates.</a> <a data-t="310">As an experiment in nlmixr2.7.0,</a> <a data-t="317">we can also skip that step.</a> <a data-t="317">The new variational autoencoder estimator searches for covariates</a> <a data-t="323">by itself.</a> <a data-t="323">Given the base model, it found weight 2.</a> <a data-t="323">Here's what the VAE search picked.</a> <a data-t="330">On clearance, it found a power of weight with an exponent of about 0.63 close to the textbook</a> <a data-t="336">three quarters.</a> <a data-t="336">On volume, it found a hockey stick that bends at 1.3 kilograms, steeper</a> <a data-t="341">for the smallest babies.</a> <a data-t="341">It chose weight for both parameters.</a> <a data-t="341">Volume variability dropped</a> <a data-t="347">further to 14 percent.</a> <a data-t="347">Before we use this model for dosing, we need to check that we</a> <a data-t="354">can believe it.</a></p>

<h3>Checking the model</h3>

<p><a data-t="356">First, let's look at individual profiles.</a> <a data-t="356">Infants 56 and 28 gave one measurement each,</a> <a data-t="363">and both still get a full concentration curve.</a> <a data-t="363">Their individual and population curves nearly</a> <a data-t="368">overlap.</a> <a data-t="368">With one data point, there's nothing to pull the infant away from typical, and</a> <a data-t="372">that's the right behavior.</a> <a data-t="372">Infants 2 and 8 have three samples each, and their curves</a> <a data-t="378">separate.</a> <a data-t="378">Now there's enough information to say this baby isn't typical.</a></p>

<p><a data-t="383">Second, a prediction-corrected visual predictive check.</a> <a data-t="383">We simulate the study many times from</a> <a data-t="390">the fitted model and ask whether the real data look like one of those draws.</a> <a data-t="390">The observed</a> <a data-t="395">median and 5th and 95th percentiles, the solid and dashed lines, stay inside the simulated</a> <a data-t="401">bands.</a> <a data-t="401">With only 155 observations, the percentiles are noisy, but the model isn't misspecified.</a></p>

<h3>Comparing flat versus weight-based dosing</h3>

<p><a data-t="410">Now we can answer the question we started with.</a> <a data-t="410">We compare two regimens.</a> <a data-t="410">The flat one</a> <a data-t="416">gives every infant a 30 mg loading dose, then 1.9 mg every 12 hours.</a> <a data-t="416">That's right</a> <a data-t="422">for a 1.5 kg baby.</a> <a data-t="422">The weight-based one gives 20 mg per kg to load, then 1.25 per kg.</a> <a data-t="422">The</a> <a data-t="431">simulation passes the fitted object straight to RxSolve.</a> <a data-t="431">It samples 400 new infants at</a> <a data-t="436">each weight from the estimated variability.</a> <a data-t="436">The model we simulate from is exactly the</a> <a data-t="441">model we fit.</a></p>

<p><a data-t="441">Here's the result.</a> <a data-t="441">The gray band is the 15 to 40 mg per liter window.</a> <a data-t="449">The flat regimen, in red, hits the window at 1.5 kg because that's what it was designed</a> <a data-t="455">for, but it slopes down across the weight range.</a> <a data-t="455">Too high for the smallest babies, too</a> <a data-t="459">low for the largest.</a> <a data-t="459">The weight-based regimen, in teal, stays flat and inside the window</a> <a data-t="464">at every weight.</a> <a data-t="464">Here are the numbers.</a> <a data-t="464">At 1.5 kg, the flat dose puts almost every infant</a> <a data-t="473">in the window.</a> <a data-t="473">At 0.7 kg, the median infant is at 41, above the window.</a> <a data-t="473">At 3.1 kg, the</a> <a data-t="480">median has dropped to 12, and fewer than 4% of infants reach the window at all.</a> <a data-t="480">With weight-based</a> <a data-t="485">dosing, 96% or more are in the window at every weight, and that weight was in the dataset</a> <a data-t="491">all along.</a></p>

<h3>nlmixr2 in the wider R ecosystem</h3>

<p><a data-t="515">Finally, where does all this sit in R?</a> <a data-t="515">Nothing we did required leaving R.</a> <a data-t="515">The fit object</a> <a data-t="524">is a data frame, so every plot here is plain </a><a href="/software/ggplot2/">ggplot2</a><a data-t="524">, and every summary is plain dplyr.</a> <a data-t="530">There's no export step and no intermediate file format.</a> <a data-t="530">That's not just convenient.</a> <a data-t="530">Analyses</a> <a data-t="536">usually break at the boundaries between tools, and this workflow doesn't have any.</a> <a data-t="542">Add </a><a href="/software/renv/">renv</a> <a data-t="542">to PIM packages and targets to rerun only what changed, and someone else can rebuild</a> <a data-t="546">the dosing recommendation from the raw data.</a></p>

<p><a data-t="546">nlmixr2 isn't a walled garden.</a> <a data-t="546">That's unusual</a> <a data-t="554">in this field, and it may be the strongest practical reason to use it.</a> <a data-t="554">babelmixr2 runs</a> <a data-t="559">the same model object through NONMEM or Monolix, so you can fit in nlmixr2 and confirm in NONMEM.</a> <a data-t="566">It also connects to PopED for optimal experimental design.</a> <a data-t="566">Going the other way, NONMEM to R,</a> <a data-t="572">X, and Monolix to Rx bring finished runs into R, so years of legacy models can be simulated</a> <a data-t="578">and checked with the same tools.</a> <a data-t="580">Underneath it all, RxODE2 solves both the fits and the</a> <a data-t="584">simulations, and there's no license to negotiate, so any collaborator can run your analysis</a> <a data-t="590">today.</a></p>

<p><a data-t="590">Getting started is a smaller step than it</a> <a data-t="595">looks.</a> <a data-t="595">Everything in this talk is about 40 lines of code.</a> <a data-t="595">Install nlmixr2 from CRAN,</a> <a data-t="601">and on Windows, install RTools2.</a> <a data-t="610">From there, the nlmixr2 website has the model, language,</a> <a data-t="608">and worked examples.</a> <a data-t="608">nlmixr2lib has starting models.</a> <a data-t="608">If you're coming from NONMEM, NONMEM</a> <a data-t="614">to Rx will translate a model you already trust, and nlmixr2 7.0 makes FOCEI solve in parallel.</a></p>

<p><a data-t="624">To sum up, 155 scattered concentrations were enough to model 59 infants.</a> <a data-t="624">Body weight explains</a> <a data-t="631">more than half of the variability between them.</a> <a data-t="631">A flat dose is right only for the baby</a> <a data-t="635">it was designed for, while weight-based dosing keeps nearly every simulated infant in the</a> <a data-t="641">window.</a> <a data-t="641">And the whole analysis is one R document that also connects to the rest of the field.</a> <a data-t="647">Whether your data come from sports analytics, supply chains, or neonatal wards, the shape</a> <a data-t="651">of the problem is the same.</a> <a data-t="651">Few observations per subject, a mechanistic model, and a decision</a> <a data-t="657">someone has to make.</a> <a data-t="657">Thanks for listening.</a> <a data-t="657">From Matt, Janice, and Pudding.</a></p>
