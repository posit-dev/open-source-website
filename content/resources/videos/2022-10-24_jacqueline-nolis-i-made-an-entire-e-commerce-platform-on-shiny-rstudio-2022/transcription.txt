<h3>How ggirl works</h3>

<p><a data-t="188">So that was the demo.</a> <a data-t="189">As you saw, it went from R to a Shiny app to Stripe, and then somehow a postcard appeared.</a> <a data-t="195">But how does it work?</a> <a data-t="196">How does it work?</a> <a data-t="197">How does it work?</a> <a data-t="198">There we go.</a> <a data-t="199">How does it work?</a> <a data-t="200">Okay.</a> <a data-t="201">So there's an R package called Gigi IRL.</a> <a data-t="202">That's what you install on your computer and talks to Shiny server.</a> <a data-t="203">And then there's a Shiny server called Gigi IRL server, which does all the work of showing</a> <a data-t="214">the user preview, passing the information to Stripe, fulfilling the postcard via an</a> <a data-t="218">API, so there's a service somewhere I call to make the postcard go, and then sends a</a> <a data-t="222">confirmation email.</a></p>
