<h3>What is a display table?</h3>

<p><a data-t="58">So the big question with display tables is, what is a display table?</a> <a data-t="63">So essentially, Great Tables is a Python library for creating publication-ready tables.</a> <a data-t="70">And what we mean by that is less like the table on the left, which is a raw Polars data</a> <a data-t="75">frame, and more like the table on the right, which is a formatted, styled, beautified table</a> <a data-t="83">that you might put in a report.</a></p>

<p><a data-t="86">And the big reason is the table on the left is really useful if you're doing data analysis.</a> <a data-t="90">You really want to know the names of your columns.</a> <a data-t="93">You want to see all of your data.</a> <a data-t="95">But the table on the right's really useful when you want to hand it off to someone and</a> <a data-t="99">to publish insights and try to spur people to action.</a> <a data-t="103">So Great Tables is all about the table on the right.</a></p>
