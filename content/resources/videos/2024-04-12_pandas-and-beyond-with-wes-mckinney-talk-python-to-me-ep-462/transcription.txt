<h3>What is Pandas?</h3>

<p><a data-t="499">It's a data manipulation and analysis toolkit for Python.</a> <a data-t="505">It's a Python library that you install that enables you to read data files,</a> <a data-t="510">so read many different types of data files off of disk or off of remote storage</a> <a data-t="515">or read data out of a database or some other remote data storage system.</a> <a data-t="520">This is tabular data, so it's structured data like with columns.</a> <a data-t="524">You can think of it like a spreadsheet or some other tabular data set.</a> <a data-t="528">And then it provides you with this data frame object,</a> <a data-t="535">which is kind of pandas.dataframe, that is the main tabular data object.</a> <a data-t="540">And it has a ton of methods for accessing, slicing, grabbing subsets of the data,</a> <a data-t="547">applying functions on it that do filtering and subsetting and selection,</a> <a data-t="552">as well as more analytical operations like things that you might do</a> <a data-t="556">with a database system or SQL, so joins and lookups,</a> <a data-t="561">as well as analytical functions like summary statistics,</a> <a data-t="564">grouping by some key and producing summary statistics.</a></p>

<p><a data-t="569">So it's basically a Swiss army knife for doing data manipulation,</a> <a data-t="574">data cleaning, and supporting the data analysis workflow.</a> <a data-t="578">But it doesn't actually include very much as far as actual statistics or models</a> <a data-t="583">or if you're doing something with LLMs or linear regression</a> <a data-t="588">or some type of machine learning, you have to use another library,</a> <a data-t="592">but pandas is the on-ramp for all of the data into your environment in Python.</a> <a data-t="599">So when people are building some kind of application that touches data in Python,</a> <a data-t="604">pandas is often the initial on-ramp for how data gets into Python,</a> <a data-t="610">where you clean up the data, you regularize it, you get it ready for analysis,</a> <a data-t="615">and then you feed the clean data into the downstream statistical library</a> <a data-t="622">or data analysis library that you're using.</a></p>

<p><a data-t="625">That whole data wrangling side of things, right?</a> <a data-t="628">Yeah, that's right.</a> <a data-t="631">And so it's some history.</a> <a data-t="635">So Python had arrays like matrices and what we call tensors now,</a> <a data-t="642">multidimensional arrays going back all the way to 1995,</a> <a data-t="646">which is pretty early history for Python.</a> <a data-t="651">The Python programming language has only been around since 1990 or 1991,</a> <a data-t="655">if my memory serves.</a> <a data-t="658">But what became NumPy in 2005, 2006 started out as numeric in 1995,</a> <a data-t="665">and it provided numerical computing, multidimensional arrays, matrices,</a> <a data-t="670">the kind of stuff that you might do in MATLAB,</a> <a data-t="672">but it was mainly focused on numerical computing</a> <a data-t="675">and not with the type of business data sets that you find in database systems,</a> <a data-t="680">which contain a lot of strings or dates or non-numeric data.</a></p>

<p><a data-t="2708">So in, like around the mid 2010s, 2015, I started working</a> <a data-t="2714">at Cloudera, which is a company that was like one of the pioneers in</a> <a data-t="2720">the big data ecosystem. <p><a data-t="2754">And I started thinking about, you know, what if it was possible to build some of the underlying</a> <a data-t="2761">computing technology, like data readers, like file readers, all the algorithms that power</a> <a data-t="2768">the core components of pandas, like group operations, aggregations, filtering selection,</a> <a data-t="2775">all those things. <p><a data-t="2809">And one of the problems we realized we needed to solve, this was like a group of other open source developers and me,</a> <a data-t="2815">was that we needed to create a way to represent data that was not tied to a specific programming</a> <a data-t="2821">language. <p><a data-t="2970">And the goal ultimately was that we, in the future,</a> <a data-t="2975">which is now, we don't want people to have to reinvent the wheel whenever they're building</a> <a data-t="2981">something like Pandas, that they could just pick up these off the shelf components.</a> <a data-t="2985">They can design the developer experience, the user experience that they want to create.</a> <a data-t="2990">And they can get built, you know, so if you were building Pandas now, you could build</a> <a data-t="2996">a Pandas-like library based on the Arrow components in much less time.
