description: 'Shiny is an R package for building interactive web applications from R code, with no JavaScript required. A Shiny app has a user interface that collects inputs and a server function that reacts to them, so when a reader moves a slider the plot updates without a page reload. This talk builds a dashboard with shinydashboard, adds a Leaflet map and a brushable ggplot, and compares the ways you can put it in front of other people. With Winston Chang.


  What you will learn

  - What a dashboard is for, and what separates a dynamic one from a static report

  - How a Shiny app is structured: inputs, the server function and reactivity

  - How to install Shiny and shinydashboard and lay out a page

  - What the Bootstrap grid gives you, and how boxes, sidebars and headers fit into it

  - How to put an interactive Leaflet map inside a Shiny app

  - How brushing lets a reader select points on a ggplot and filter everything else

  - The deployment options: Shiny Server open source, Shiny Server Pro and shinyapps.io
