description: 'Plumber turns R functions into HTTP endpoints. You add a comment above a function saying which path and which method it answers, and Plumber serves it as a REST API, so a model written in R can be called from Python, JavaScript, a database job or anything else that speaks HTTP. This session builds one from scratch, parses incoming JSON, generates an OpenAPI interface, and deploys it to Posit Connect. With James Blair and Barret Schloerke.


  What you will learn

  - What an API is in this context, and why an R model benefits from being one

  - How Plumber decorators turn a plain R function into an endpoint

  - How to build an API one endpoint at a time, starting with a health check

  - How to parse the body of an incoming request

  - What OpenAPI gives you, and how the generated interface lets people try the API in a browser

  - How serializers control what comes back, and how to switch between JSON and CSV

  - How to deploy the finished API to Posit Connect

  - What to think about for security, rate limits and customisation
