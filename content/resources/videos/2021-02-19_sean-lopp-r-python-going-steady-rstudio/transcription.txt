<h3>The craftsman analogy</h3>

<p><a data-t="68">Now, to set some context, imagine you're a craftsman, someone who is handy and builds</a> <a data-t="75">things.</a> <a data-t="76">As a craftsman, you'd probably be familiar with screwdrivers.</a> <a data-t="78">I mean, who hasn't used a screwdriver to put something together?</a> <a data-t="83">And you might be aware that screwdrivers come in a variety of different shapes and forms.</a> <a data-t="87">You can have a flathead screwdriver, a star bit, a Phillips head, and each of these screwdrivers</a> <a data-t="93">is designed to serve a specific purpose.</a></p>

<p><a data-t="96">Now imagine as a craftsman, if you were told that you have to choose for the rest of your</a> <a data-t="100">career between using one type of screwdriver or another, you'd probably look at that person</a> <a data-t="107">and say, that's crazy.</a> <a data-t="109">There's no way I can practically make this choice.</a> <a data-t="111">For some projects, I'm going to need a flathead.</a> <a data-t="113">For other projects, I'll need a Phillips.</a> <a data-t="115">It doesn't make sense for me to pick one screwdriver to use for the rest of my career.</a></p>

<p><a data-t="120">Instead, what you might do as a craftsman is to say, I want to opt in to using a smarter</a> <a data-t="128">tool, a tool that's going to be more powerful and allow me to take advantage of all these</a> <a data-t="133">different bits that are out there.</a> <a data-t="136">Specifically, as a craftsman, you might be interested in something like a drill, a tool</a> <a data-t="141">that regardless of what bit you're going to need for a project, allows you to work faster</a> <a data-t="147">and to accomplish more and allows you to work in an easier fashion.</a></p>

<p><a data-t="153">So craftsmen have this drill.</a> <a data-t="156">What about data science teams?</a> <a data-t="157">Well, I believe as data scientists, we should refuse that same false choice between R and</a> <a data-t="164">Python and other languages, just as the craftsman refuses to pick one type of screwdriver.</a> <a data-t="170">Instead, we should work alongside of folks in IT and the leaders of our teams to build</a> <a data-t="176">something like a drill, something that regardless of what language we use, is going to give</a> <a data-t="181">us the power to accomplish our projects faster and easier.</a></p>
