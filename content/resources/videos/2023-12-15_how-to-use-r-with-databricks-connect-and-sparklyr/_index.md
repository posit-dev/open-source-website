description: 'Spark Connect lets you talk to a remote Spark cluster over a network connection rather than running inside it, which means you can work with Databricks from your own laptop in RStudio or Positron instead of opening a notebook in the Databricks workspace. sparklyr supports it through pysparklyr: upgrade sparklyr, install the Python components, supply a cluster ID and a token, and you have a connection you can drive with ordinary dplyr code. With Edgar Ruiz, who maintains sparklyr.


  What you will learn

  - What Spark Connect is, and what changed when it arrived

  - Why the connection goes through Python, and what pysparklyr installs for you

  - How local Spark and Spark Connect differ in practice

  - What you need to connect to Databricks: the cluster ID and a token

  - Why you should never put a token in your code

  - How to preview tables and explore the data from your editor

  - How dplyr code runs against a Spark table

  - What the current limitations are with Spark 3.4

  - How reticulate gets you the rest of the API when sparklyr does not wrap it
