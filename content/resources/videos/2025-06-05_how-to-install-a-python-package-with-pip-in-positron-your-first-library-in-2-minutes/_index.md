description: 'To install a Python library, open a terminal and run pip install followed by the package name. pip is Python''s package manager: it downloads the library and everything it depends on from the Python Package Index, so one command is usually all it takes. To see what is already installed, run pip freeze, which lists every package with its version number. Saving that output to a file called requirements.txt is how you reproduce the same environment somewhere else.
