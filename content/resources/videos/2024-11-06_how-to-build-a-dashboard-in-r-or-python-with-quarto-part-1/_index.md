description: 'A Quarto dashboard is a .qmd file with dashboard as its output format. Headings become the layout: level one headings make pages, level two make rows or columns, and each code chunk becomes a card. The code itself is hidden in the output, so the reader sees only the result. The same document works in R or in Python, and this part builds it both ways using Olympics data. With Mine Cetinkaya-Rundel.


  What you will learn

  - What a Quarto dashboard is, and how it differs from a Shiny app

  - How pages, rows, columns, tabsets and cards fit together

  - Why your headings become the layout, and how to plan them

  - How the YAML header controls the format, the theme and the logo

  - How to build the same dashboard in R and in Python

  - Why the code is hidden by default in dashboard format

  - How to give cards titles, set the orientation, and control heights and widths
