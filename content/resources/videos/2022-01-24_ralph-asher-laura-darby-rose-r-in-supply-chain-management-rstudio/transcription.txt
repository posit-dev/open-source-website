<h3>What is supply chain network design?</h3>

<p><a data-t="439">So, what is supply chain network design?</a> <a data-t="439">Put plainly, it's the</a> <a data-t="446">strategic analysis of the locations and activities of the various elements of a firm's supply</a> <a data-t="450">chain.</a> <a data-t="450">For example, if I'm a manufacturer, where should I locate warehouses for my raw</a> <a data-t="455">materials, the stuff I use to make other stuff, or my semi-finished goods, which are items</a> <a data-t="460">that are only partway through the manufacturing process?</a> <a data-t="460">Where should I put my manufacturing</a> <a data-t="465">facilities, my plants?</a> <a data-t="465">Where should they go?</a> <a data-t="465">Where should I put my distribution centers,</a> <a data-t="469">my warehouses for finished goods?</a> <a data-t="469">Where should they be located?</a> <a data-t="469">And if I'm a retailer, how</a> <a data-t="476">should I use my stores as a link in my supply chain?</a> <a data-t="476">For example, many leading retailers,</a> <a data-t="481">including my former employer, Target, use their stores as strategic assets for shipping</a> <a data-t="485">e-commerce orders.</a> <a data-t="485">Well, from where should we do that?</a> <a data-t="485">That's a big question.</a> <a data-t="485">That's a</a> <a data-t="489">supply chain network design question.</a> <a data-t="489">Supply chain network design seeks to answer these</a> <a data-t="494">big questions, all with the intent to understand the impacts on profitability, cost, service,</a> <a data-t="499">and other key metrics, and with the goal to minimize or maximize one or two key metrics,</a> <a data-t="503">usually cost or profitability.</a></p>

<p><a data-t="503">Today, I'll be focusing on a relatively simple example</a> <a data-t="509">of supply chain network design, a distribution network with two echelons, the distribution</a> <a data-t="514">centers, or warehouses, and customers that are serviced by those warehouses.</a> <a data-t="514">In designing</a> <a data-t="520">a supply chain, we ask ourselves, given a customer base of demand aggregated to a city</a> <a data-t="524">level, one, where should we open distribution centers to satisfy that demand?</a> <a data-t="524">And two, what</a> <a data-t="530">customers should be serviced by or aligned to each distribution center?</a> <a data-t="530">While most real</a> <a data-t="535">life supply chain design problems are much, much more complex than this example, I hope</a> <a data-t="539">it will be informative on how practitioners approach these kinds of problems and how we</a> <a data-t="543">can use open source technology for them.</a></p>

<p><a data-t="783">When we use mathematical optimization, including for supply chain design, we're trying to minimize</a> <a data-t="787">or maximize some equation that is the function of our decisions.</a> <a data-t="787">In this example, Heartland Widgets</a> <a data-t="792">wants to design the supply chain with the lowest total cost.</a> <a data-t="792">The supply chain costs in this example</a> <a data-t="797">are, one, the opening costs for distribution centers, which are priced at $1 million each,</a> <a data-t="802">two, the handling costs of the distribution centers, which is one cent per unit per widget,</a> <a data-t="807">and three, the transportation costs from distribution centers to customers, which are five cents</a> <a data-t="811">per unit mile.</a> <a data-t="811">Now, a unit mile is moving one unit one mile.</a> <a data-t="811">So, for example, if you have two widgets,</a> <a data-t="818">two units, and you move them 100 miles, that's two times 100, 200 unit miles.</a> <a data-t="818">At five cents each,</a> <a data-t="824">that's $10 to move two units 100 miles.</a> <a data-t="824">You add up these three components, cost components,</a> <a data-t="831">and that leads to the total supply chain costs that we're trying to minimize.</a></p>
