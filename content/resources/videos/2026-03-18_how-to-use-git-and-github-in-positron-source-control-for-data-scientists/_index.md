  What you will learn

  - What Git and GitHub each do, and why a data scientist needs them

  - How to turn a Positron project into a Git repository and publish it to GitHub

  - What belongs in a .gitignore, and why

  - How to stage, commit and push, and how to undo a commit you did not mean to make

  - How branches, stashes and pull requests work in practice

  - How to set branch protection rules and add a collaborator

  - How to resolve a merge conflict when two people change the same lines

  - Whether to do this in Positron or in the GitHub web interface
