description: 'Quarto is an open-source publishing system from Posit. You write one .qmd file containing text and R or Python code, then render it to an HTML page, a PDF, reveal.js slides or a whole website. If you already use R Markdown, the file extension changes from .Rmd to .qmd and the YAML header works the same way. This walkthrough builds a document, a set of slides and a website, and publishes them. With Mine Cetinkaya-Rundel.


  What you will learn

  - What Quarto is, and how it relates to R Markdown

  - How to author a .qmd file in the RStudio visual editor

  - What chunk options do, and how to control what appears in the output

  - How to cross-reference figures and tables so the numbering looks after itself

  - How to insert a citation from a DOI

  - How to switch from HTML to PDF to slides without rewriting the document

  - How to build a website from scratch and publish it to Quarto Pub
