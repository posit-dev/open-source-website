<p><a data-t="399">So not only is it problematic just from a programming standpoint, just even if this</a> <a data-t="403">code would work, it's kind of a bad idea because you end up having many, many variations or</a> <a data-t="408">the same data set included many times.</a> <a data-t="410">So this is not a terribly obscure thing to do, but it does limit you to what you can</a> <a data-t="417">do in the formula method.</a></p>
