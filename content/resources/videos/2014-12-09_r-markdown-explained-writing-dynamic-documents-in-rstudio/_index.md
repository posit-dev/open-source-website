description: 'R Markdown is a file format that holds narrative text and runnable R code in the same document. You write in Markdown, add code chunks, and render the file to HTML, PDF or Word with the results of the code included. That means the numbers, tables and charts in a report come from the code that produced them, so the report can be rebuilt from source whenever the data changes. With Jeff Allen.


  What you will learn

  - What R Markdown is, and what a .Rmd file contains

  - How Markdown formatting turns into a finished document

  - How code chunks run and place their output in the report

  - How to build a custom template so a house style is applied once rather than every time

  - Where R Markdown fits now that Quarto exists


  Chapters

  1:10 What an .Rmd file looks like

  8:25 Building a custom template

  12:55 Where to go next


  Learn more

  Quarto, the successor to R Markdown: https://quarto.org

  Quarto for R Markdown users: https://quarto.org/docs/faq/rmarkdown.html


  R Markdown is fully supported and is not going away. Quarto is the next generation of the same idea, and existing .Rmd files keep working.'
