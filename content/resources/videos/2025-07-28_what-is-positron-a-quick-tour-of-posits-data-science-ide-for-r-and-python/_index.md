description: 'Positron is Posit''s data science IDE for R and Python. It is built on VS Code and informed by Posit''s work on RStudio, so the layout will feel familiar, and it adds a Data Explorer, an interpreter picker that switches between R and Python in one session, and Positron Assistant for generating and debugging code. Download it at https://positron.posit.co.


  What you will learn

  - How Positron relates to RStudio and to VS Code, and what it adds to both

  - What happens when you open a folder, and why it works like an RStudio project

  - What sits in the activity bar, the primary sidebar and the secondary sidebar

  - How to switch between R and Python, and between versions of each

  - How the Data Explorer lets you filter, sort and read summary statistics without writing code

  - What Positron Assistant''s ask, edit and agent modes each do

  - How to pull up function documentation inside the IDE
