<h3>When is a human the better choice?</h3>

<p><a data-t="791">So equipped with these ideas</a> <a data-t="793">of the kind of stretch zone projects</a> <a data-t="796">and using the LLM as a tutor,</a> <a data-t="798">I decided to take these ideas</a> <a data-t="800">and apply them to a completely different project.</a> <a data-t="803">And this brings me to my third and final question.</a> <a data-t="806">When is a human the better choice?</a></p>

<p><a data-t="809">So I'm one of the maintainers of the arrr package,</a> <a data-t="812">and I decided I wanted to have a go</a> <a data-t="814">at contributing to Pyarrow, the Python arrow implementation.</a> <a data-t="819">I decided to work on a task related to magic methods.</a> <a data-t="822">Now, if you don't know what they are,</a> <a data-t="823">it doesn't matter too much for this,</a> <a data-t="825">but it felt like the perfect stretch zone task</a> <a data-t="828">in that I've got experience of the arrr package,</a> <a data-t="831">I can write some Python,</a> <a data-t="833">but I didn't know much about Pyarrow</a> <a data-t="835">and very little about the internals of Python libraries in general.</a> <a data-t="838">So it kind of felt in the right place.</a></p>

<p><a data-t="840">So next, I needed to figure out what role I wanted the LLM to play.</a> <a data-t="845">So I decided that I was going to write most of the code.</a> <a data-t="848">In this case, you know, this task for me was about learning.</a> <a data-t="851">So I needed to do that myself, really.</a> <a data-t="853">I also wanted to write the test,</a> <a data-t="855">just so I could be really clear</a> <a data-t="856">about what the intentions of the code that I was writing.</a> <a data-t="859">And I was going to get the LLM to help me with any code tweaks.</a> <a data-t="863">Maybe there's bits of how things are done in Python</a> <a data-t="865">that I don't really kind of get with package internals.</a> <a data-t="868">So I was going to use it to help me understand errors</a> <a data-t="871">and to explain any new concepts, like magic methods,</a> <a data-t="873">which I had no idea what they were at the time.</a></p>

<p><a data-t="876">But also, I had some other help from my friend, Elenka,</a> <a data-t="880">who is a Pyarrow maintainer,</a> <a data-t="882">and she was just going to jump in anywhere I got stuck.</a></p>
