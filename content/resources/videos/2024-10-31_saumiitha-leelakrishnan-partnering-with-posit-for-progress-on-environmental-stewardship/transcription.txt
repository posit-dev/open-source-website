<h3>Step one: grasp your needs</h3>

<p><a data-t="129">So step one, grasp your needs.</a> <a data-t="134">So for all of you in this room to understand</a> <a data-t="136">the needs of this specific project,</a> <a data-t="138">I think I would have to give a picture of what our team does</a> <a data-t="142">and what is the data.</a> <a data-t="144">So we are a functional excellence team</a> <a data-t="147">who are responsible for creating tools and processes</a> <a data-t="151">for onboard diagnostics and emissions compliance data.</a></p>

<h3>Advancing with machine learning</h3>

<p><a data-t="490">So now we have a web application.</a> <a data-t="493">Engineers can use it.</a> <a data-t="495">They can derive insights from it.</a> <a data-t="497">They have action items to work on.</a> <a data-t="501">So what is the next step?</a> <a data-t="503">Is that all there is?</a> <a data-t="504">No, we would have to advance and adapt.</a></p>

<p><a data-t="508">So in this example, I would like to say</a> <a data-t="510">that the engine serial numbers that</a> <a data-t="513">have been identified to have presumably not accumulated</a> <a data-t="519">enough of that IOMPA ratio I mentioned earlier,</a> <a data-t="522">you need some key attributes like duty cycle</a> <a data-t="525">and application so that the engineering teams can</a> <a data-t="529">go and analyze the data.</a> <a data-t="530">So how do I find the duty cycle?</a> <a data-t="532">So before then, what's a duty cycle?</a> <a data-t="535">So duty cycle is a definition of history of speed and load</a> <a data-t="540">conditions over which an engine is</a> <a data-t="542">operating over a period of time for any selected application.</a></p>

<p><a data-t="547">So I wanted to find the duty cycle with the engineering data</a> <a data-t="551">that was available in hand with me.</a> <a data-t="554">In that case, I jumped into using</a> <a data-t="557">the simplest and the popular unsupervised machine learning</a> <a data-t="560">model, which is k-means clustering.</a> <a data-t="563">I utilized this Python library for it.</a> <a data-t="566">So I worked with subject matter experts</a> <a data-t="569">to identify five engine features based on the characteristics</a> <a data-t="575">to determine the duty cycle.</a> <a data-t="577">So it was idle percent, torque curve percent,</a> <a data-t="581">motoring percent, key cycles per hour,</a> <a data-t="584">and drive cycle average percent.</a></p>

<p><a data-t="587">So once I identified these engine features,</a> <a data-t="592">how I used it in the model is that how this k-means</a> <a data-t="596">clustering model works is that it first randomly assigns</a> <a data-t="600">a data point to one of your clusters,</a> <a data-t="603">and then you compute the centroid of each cluster.</a> <a data-t="606">Then there is reassignment of your centroid of each data</a> <a data-t="609">point to the nearest centroid of your cluster.</a> <a data-t="612">And this continues going until there</a> <a data-t="614">is no changing of your clusters happening.</a> <a data-t="617">Thus, finally, you're able to identify your duty</a> <a data-t="620">cycle of each of the engine serial numbers out there.</a></p>

<p><a data-t="624">So that will give an insight on what conditions</a> <a data-t="628">do you think those engines were not</a> <a data-t="631">able to accumulate enough of the IOMPR ratio.</a></p>
