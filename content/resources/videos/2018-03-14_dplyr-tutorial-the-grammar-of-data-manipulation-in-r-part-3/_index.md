description: 'dplyr is the tidyverse package for transforming data, built around six verbs: select picks columns, filter picks rows, mutate adds new columns, summarise collapses many rows into one, arrange sorts, and group_by makes the others operate within groups instead of across the whole table. The pipe joins them into a chain you can read out loud as a sentence.


  What you will learn

  - What each of the six dplyr verbs does, with a worked example of each

  - How select specifies columns in ways square brackets cannot

  - How filter drops rows, and what it does with NA values

  - How mutate can use a column it just created

  - Why summarise returns a much smaller data frame, and what that is for

  - How the pipe turns nested calls into a readable chain

  - What group_by changes, how ungroup undoes it, and why grouped data can surprise you
