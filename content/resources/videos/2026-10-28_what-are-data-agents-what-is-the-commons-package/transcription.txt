<h3>Introducing the Commons package</h3>

<p><a data-t="151">These are exactly the problems that we're trying to solve in a new open source package called Commons.</a> <a data-t="160">Commons is a tool for data scientists to build trustworthy data agents for their collaborators.</a> <a data-t="168">And those data agents are designed to be more correct, more reproducible, and more transparent than coding</a> <a data-t="181">agents that are most popular.</a> <a data-t="181">It's open source in both R and Python, and it's built on our open source AI stack with </a><a href="/software/shiny-r/">Shiny</a><a data-t="181">, Elmer, and Chatless.</a> <a data-t="191">And you can use it with whatever model from whatever provider that you want.</a> <a data-t="198">I'm often asked why it is that there's a bird on the hex.</a> <a data-t="206">This is a common kingfisher.</a> <a data-t="206">So Commons, common.</a></p>

<p><a data-t="206">One of the core ideas behind Commons is this concept of trusted code.</a> <a data-t="216">So I mentioned earlier that the data team already has all sorts of code that produces analysis that is trusted by their collaborators and within their organization.</a> <a data-t="231">So this could be R packages, Python packages, Quarto reports, Shiny apps,</a> <a data-t="238">semantic views inside of databases like Databricks or Snowflake.</a> <a data-t="238">And one of the questions that Commons tries to answer is what would it look like if the model could reach for this code directly rather than sort of hand authoring code on its own.</a> <a data-t="250">So instead of writing code afresh, it's just reaching for this trusted code when it's around.</a></p>

<p><a data-t="258">So in order to make that happen, Commons is doing three things.</a> <a data-t="265">The first of them is providing a data structure that you can extract all of this trusted code and metadata about what that code means and how it's interpreted</a> <a data-t="279">in the business context into this common data structure.</a> <a data-t="279">And once that data structure exists, there's also a harness, so a set of prompts and tools that's provided to an LLM to try to give</a> <a data-t="295">it the right context at the right time.</a> <a data-t="295">And finally, once these agents exist and they're deployed in production, those agents will do a bunch of work live.</a> <a data-t="303">And some of those</a> <a data-t="311">conversations will result in the agent finding code that is trusted by the organization already</a> <a data-t="318">and invoking it.</a> <a data-t="318">But some of the other questions will result in the agent having to improvise R or Python code.</a> <a data-t="325">And so in those cases where the agent has to improvise code,</a> <a data-t="332">Commons provides some tools to try to push those responses up the trust ladder,</a> <a data-t="338">allowing the data team to see what questions are being asked live</a> <a data-t="342">and add new sources of trusted code over time.</a></p>

<h3>Code as the foundation</h3>

<p><a data-t="1366">One of the primary principles that underlies Commons is that</a> <a data-t="1374">code is the foundation of what it does.</a> <a data-t="1374">And I think this sometimes can seem obvious, but isn't always</a> <a data-t="1379">obvious.</a> <a data-t="1379">And we often have to make decisions to force the model to follow this philosophy.</a> <a data-t="1379">And this</a> <a data-t="1385">is, you want code as the foundation basically of everything that the model does.</a> <a data-t="1385">And the reason</a> <a data-t="1392">this isn't a given is that LLMs can do things in their head, sort of.</a> <a data-t="1392">So, you can ask it to add</a> <a data-t="1397">two numbers together or do some kind of calculation.</a> <a data-t="1397">It doesn't have to write code to do that.</a> <a data-t="1402">It can do the calculation in its head.</a> <a data-t="1402">Then that means that that calculation is not accessible to</a> <a data-t="1407">you.</a> <a data-t="1407">It's not transparent.</a> <a data-t="1407">You can't take a look at it.</a> <a data-t="1407">You can't rerun it.</a> <a data-t="1407">And also, it's often worse.</a></p>

<p><a data-t="1414">And part of the reason is that LLMs are really good at writing code.</a> <a data-t="1414">This is one of the things</a> <a data-t="1418">that they really excel at.</a> <a data-t="1418">And we want to take advantage of that.</a> <a data-t="1418">And then the second reason is</a> <a data-t="1423">that we know from years and years of using code to do data analysis that code is reproducible,</a> <a data-t="1429">it's transparent, and it's auditable.</a> <a data-t="1429">And we don't want to throw all that away just because</a> <a data-t="1433">you have this shiny new LLM tool.</a> <a data-t="1433">So, as much as possible, we want the model to be able to write</a> <a data-t="1439">code.</a> <a data-t="1439">And so, the Commons agent runs its trusted calculation, which is code that you as the data</a> <a data-t="1445">scientists have vetted, but also when it writes custom code.</a> <a data-t="1445">It's not, you know, to the greatest</a> <a data-t="1451">extent possible, it's not doing those calculations in its head.</a> <a data-t="1451">It's writing code to get an answer.</a> <a data-t="1457">It shows you the code if you want to see it, and then it interprets it.</a></p>
