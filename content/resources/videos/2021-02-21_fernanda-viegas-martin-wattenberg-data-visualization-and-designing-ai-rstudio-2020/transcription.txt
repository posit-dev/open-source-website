<h3>The What-If Tool</h3>

<p><a data-t="1245">And so based on this and on the reaction we got, let me go back,</a> <a data-t="1256">we decided to go from that toy simulation</a> <a data-t="1258">to actually trying to put together an actual tool that</a> <a data-t="1262">allowed you to do some of this playing around with your model</a> <a data-t="1267">and with testing your model for different scenarios.</a></p>

<p><a data-t="1272">And so this is a tool we created called the What-If Tool.</a> <a data-t="1276">And this is a code-free probing tool for machine learning systems</a> <a data-t="1282">that allows you to test for some of these scenarios,</a> <a data-t="1287">to say things like, oh, what if I want demographic parity</a> <a data-t="1292">in the different slices of my data?</a> <a data-t="1294">What thresholds should I use in my model?</a></p>

<p><a data-t="1298">It allows you to do things like click on a data point and say,</a> <a data-t="1303">for instance, let's go back to the loan scenario and say,</a> <a data-t="1307">oh, this person did not get a loan, OK?</a> <a data-t="1311">Let me go back to the next slide here.</a> <a data-t="1315">This person did not get a loan.</a> <a data-t="1318">Who is the nearest person to that one that did get a loan?</a> <a data-t="1322">And what is the delta there?</a> <a data-t="1324">So a little notion of counterfactual, if you will,</a> <a data-t="1328">without the causality.</a> <a data-t="1330">That's a separate conversation.</a> <a data-t="1331">But just this notion of starting to try to understand</a> <a data-t="1335">what's happening with these systems, how they are behaving,</a> <a data-t="1338">asking a bunch of alternative scenarios,</a> <a data-t="1341">trying a bunch of edge cases, and also</a> <a data-t="1345">playing with notions of fairness,</a> <a data-t="1348">of how different slices of your data set</a> <a data-t="1351">are doing vis-a-vis one another.</a></p>

<p><a data-t="1356">This tool is open source, so it is available for anyone.</a> <a data-t="1361">It has also been integrated into Google's Cloud AI</a> <a data-t="1365">so that anyone using that platform</a> <a data-t="1369">can now play with these alternative scenarios</a> <a data-t="1372">and test things for themselves before they decide</a> <a data-t="1375">to launch something or to try to debug situations.</a></p>
