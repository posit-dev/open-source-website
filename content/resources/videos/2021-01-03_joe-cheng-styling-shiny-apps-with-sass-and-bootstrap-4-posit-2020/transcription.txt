<h3>Why CSS is hard: enter Sass</h3>

<p><a data-t="539">So why is this so difficult?</a> <a data-t="540">Why does it take so much effort to just override one color?</a> <a data-t="546">This is bootstrap CSS.</a> <a data-t="552">There's a color that's being highlighted.</a> <a data-t="554">There's a hex code.</a> <a data-t="555">And this is the source code for bootstrap CSS.</a> <a data-t="559">So this is saying that this link should be blue.</a> <a data-t="561">That very specific shade of blue.</a> <a data-t="564">This color appears all throughout the CSS file 25 different times.</a> <a data-t="570">And some of them are pretty complicated.</a> <a data-t="572">So if you as a Shiny app author want to change all of those instances of blue to that specific</a> <a data-t="578">shade of orange, you would actually have to overwrite each one of those rules with custom</a> <a data-t="582">CSS.</a> <a data-t="583">And those are pretty complicated selectors that we're looking at here.</a> <a data-t="587">So clearly this is not really a tenable strategy for changing colors.</a></p>
