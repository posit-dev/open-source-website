description: 'How to stop rebuilding the same report every month: write it once as a Quarto dashboard, schedule a script on Posit Connect that fetches the new data and stores it with pins, and let Connect re-render the dashboard on a schedule. Everyone who needs it gets the current version at a URL, and nobody has to remember to update it. Built here on monthly Consumer Price Index data from the Bureau of Labor Statistics. With Isabella Velasquez.


  What you will learn

  - Why a Quarto dashboard suits a recurring report better than a notebook

  - The layout building blocks: pages, rows, columns, tabsets, sidebars and cards

  - How to theme a dashboard so it matches your organisation

  - How to create a virtual environment so the deployment matches your machine

  - How to schedule a script on Posit Connect so new data is collected as it is published

  - What pins does, and why the data fetch is separate from the report

  - How to publish from VS Code to Posit Connect

  - How to set environment variables for credentials rather than hard-coding them
