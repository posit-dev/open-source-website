<p><a data-t="1983">So, here's a kind of a more comprehensive example.</a> <a data-t="1983">We'll take a look at this dashboard</a> <a data-t="1988">here in just a moment.</a> <a data-t="1988">But here's an example where, and this goes back to the Tableau workbook</a> <a data-t="1994">that we looked at kind of at the very beginning, where we are submitting information about a given</a> <a data-t="1999">customer and their transactions to a machine learning model that was built in Python,</a> <a data-t="2003">or generating predictions based on that input data, submitting those predictions back to Tableau,</a> <a data-t="2008">and then visualizing them in that Tableau environment.</a> <a data-t="2008">And here we see, again, the same</a> <a data-t="2013">pattern.</a> <a data-t="2013">We use this script function in our calculated fields, and then we define the path</a> <a data-t="2018">to the endpoint that we want to, or the path to the extension that we want to use, and then the</a> <a data-t="2022">values from our workbook that we want to pass into that extension.</a></p>
