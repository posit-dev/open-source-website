<h3>LLM performance and evaluation</h3>

<p><a data-t="1167">Okay.</a> <a data-t="1167">At this point or maybe previously or all the time, you might feel kind of apprehensive about LLMs.</a> <a data-t="1177">Maybe kind of like this cat encountering a Roomba.</a> <a data-t="1177">And maybe a little bit curious as well.</a> <a data-t="1183">You might have heard that LLMs can do cool things or very powerful things, but they also hallucinate, that they have privacy and security concerns, that they're wrong a lot, that they're untrustworthy, all of these things.</a> <a data-t="1195">So I'm going to talk a little bit about what LLMs are actually good for and maybe what you should avoid.</a></p>

<p><a data-t="1207">And the first thing is that LLMs are jagged.</a> <a data-t="1207">LLM performance is in some ways very unpredictable.</a> <a data-t="1217">You might think that LLM performance looks a bit like this plot where really easy tasks are very easy for the model to do.</a> <a data-t="1225">It performs great at them.</a> <a data-t="1225">But then as tasks get harder, model performance goes down.</a> <a data-t="1230">And really hard tasks are nearly impossible for LLMs.</a></p>
