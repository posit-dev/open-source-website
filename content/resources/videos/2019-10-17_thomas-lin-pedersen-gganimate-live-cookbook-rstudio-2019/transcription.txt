<h3>What is gganimate?</h3>

<p><a data-t="40">What is gganimate?</a> <a data-t="40">gganimate is a package</a> <a data-t="50">I have wrote.</a> <a data-t="50">It's kind of a two-fold thing.</a> <a data-t="50">It's both a grammar of graphics, like a</a> <a data-t="58">theoretical backbone of how to describe animation, and it's also an implementation of said</a> <a data-t="65">theoretical backbone.</a> <a data-t="65">In the same sense that there exists a grammar of graphics theory,</a> <a data-t="70">and </a><a href="/software/ggplot2/">ggplot2</a><a data-t="70"> is just one of many different implementations of this theory, what I wanted</a> <a data-t="75">to do with gganimate was also to kind of build a theoretical backbone for how to address</a> <a data-t="81">animation and data visualization.</a> <a data-t="81">It's two-fold, and on top of that, it's an extension to ggplot2,</a> <a data-t="88">so it's not something that exists on its own.</a> <a data-t="88">It is something that you can apply to any of</a> <a data-t="94">your normal ggplot2 plots and make them move magically.</a></p>

<p><a data-t="94">Lastly, gganimate is not what it was</a> <a data-t="102">a year ago.</a> <a data-t="102">gganimate actually has a long storied history, starting with years ago,</a> <a data-t="112">David Robinson, who sits down there, wrote gganimate, and he had some other thoughts than</a> <a data-t="118">me about how it should look, and he made it, and it was fantastic, and it got pretty popular,</a> <a data-t="125">and at some point he made the big mistake of asking me to take it over, and I had some</a> <a data-t="130">other thoughts.</a> <a data-t="130">So I rewrote it completely, which also means that if you have code from a</a> <a data-t="139">year ago, I can assure you that it won't run.</a> <a data-t="139">So I have broken a lot of stuff, but I think I've</a> <a data-t="147">done it for good reasons.</a> <a data-t="147">Furthermore, David never made it to CRAN with his package.</a> <a data-t="147">I did,</a> <a data-t="157">so it is now on CRAN, and you can grab it from there.</a></p>
