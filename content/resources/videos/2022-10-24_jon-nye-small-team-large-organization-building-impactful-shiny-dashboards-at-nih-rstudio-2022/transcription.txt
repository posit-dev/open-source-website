<h3>Machine learning for grant classification</h3>

<p><a data-t="539">So the next example I want to give you is how we've used machine learning to classify</a> <a data-t="544">NIAID grants.</a> <a data-t="546">So just a little background on grants at NIH.</a> <a data-t="549">There are really two main types.</a> <a data-t="552">One starts at NIH.</a> <a data-t="553">So we send out a request for applications, and this is when the NIH asks the scientific</a> <a data-t="560">community to apply for funding in a very specific, well-defined area.</a> <a data-t="565">We usually use these to stimulate research in really high-priority areas.</a> <a data-t="569">The next type of application is the investigator-initiated application.</a> <a data-t="573">So instead of starting at NIH, we're starting with that investigator or scientist that's</a> <a data-t="579">running a lab somewhere, right?</a> <a data-t="581">So these make up by far the majority of our applications, greater than 85%.</a></p>

<p><a data-t="587">And so at NIH, we really have to rely on the scientific community, the creativity and ingenuity</a> <a data-t="594">that they have to come up with innovative research ideas.</a> <a data-t="598">And those ideas can be very broad and cross-cutting or very narrow and well-defined.</a> <a data-t="602">But when we get those applications, these investigator-initiated ones, we don't have</a> <a data-t="606">much information on it.</a> <a data-t="608">Besides that, it falls in the broad research areas of NIAID's mission.</a> <a data-t="614">So you can imagine that this is very difficult, right?</a> <a data-t="616">When you're dealing with thousands of applications, how do we know how much we've funded and what</a> <a data-t="622">projects we've funded in a specific research area?</a> <a data-t="625">So we get questions all the time.</a> <a data-t="626">How much have you spent on HIV vaccine research or how much have you spent on tuberculosis</a> <a data-t="633">research and what projects?</a> <a data-t="635">And we need to be able to answer those questions.</a></p>

<p><a data-t="638">So how do we do that?</a> <a data-t="640">The answer is we have a team for that.</a> <a data-t="643">So every year, NIAID gets over 9,000 grant applications, and we fund about 20% of these,</a> <a data-t="649">give or take.</a> <a data-t="650">We then have a team of about three to six people that go through these awarded grants</a> <a data-t="654">and apply codes based on the research being proposed.</a> <a data-t="657">So they have over 1,300 unique codes that they can use to describe that research.</a> <a data-t="664">And I've included a few examples here on the right.</a> <a data-t="667">So they look, are they researching a specific disease like Ebola or Zika?</a> <a data-t="671">Is the research area, you know, new therapeutics or diagnostics and so on?</a></p>

<p><a data-t="678">But you can imagine with thousands of grants, this can be challenging.</a> <a data-t="682">First, it's very time intensive.</a> <a data-t="684">So they have to go through thousands of these awarded grants and read the title, the abstract,</a> <a data-t="690">the specific aims, and describe that research.</a> <a data-t="694">Because it's so time consuming, we only have the resources to code awarded grants.</a> <a data-t="699">The 80% of applications that are unfunded, we don't have any information on.</a> <a data-t="705">And they have a constantly increasing workload.</a> <a data-t="707">So every year, we're getting more applications and giving out more awards.</a> <a data-t="711">And especially at the beginning of the pandemic, this was, we saw a huge increase in applications</a> <a data-t="715">due to COVID research.</a> <a data-t="718">And finally, because it takes so much time, this usually isn't done until the very end</a> <a data-t="721">of the year.</a> <a data-t="722">So we don't have real time data on this, which would be helpful.</a></p>

<p><a data-t="726">So we thought this was a great opportunity to use supervised machine learning for grant</a> <a data-t="730">classification.</a> <a data-t="731">We had a database of thousands of grants that had been manually coded over the past decade</a> <a data-t="736">that we could use to train machine learning models.</a> <a data-t="739">So here's an example of a grant that's proposing to research a more sensitive diagnostic for</a> <a data-t="745">tuberculosis.</a> <a data-t="747">When I looked up the codes on this grant, you could see the disease was tuberculosis.</a> <a data-t="752">The research area was diagnostics, and it was a clinically focused grant.</a></p>

<p><a data-t="756">So I just want to give you one example of how we've used machine learning to classify</a> <a data-t="761">grants based on the research area.</a> <a data-t="763">So here, it was diagnostics.</a> <a data-t="766">But there are five categories, including therapeutic, prevention, and vaccine.</a> <a data-t="771">So we took about 7,500 grants that had previously been manually coded and used them to train</a> <a data-t="779">three different machine learning models, including logistic regression, support vector machine,</a> <a data-t="783">and random forest to compare the three.</a> <a data-t="786">We then tested these models using about 3,200 grants that had also been manually coded.</a> <a data-t="793">And so what we found was the logistic regression was the most accurate, 88.5%.</a> <a data-t="798">And it also did the best at predicting this relatively small category of grants in the</a> <a data-t="802">prevention class.</a></p>

<p><a data-t="805">So we use this machine, this logistic regression model, to build a Shiny dashboard for coding</a> <a data-t="811">NIAID grants.</a> <a data-t="812">And we then expanded it to assist in coding in five additional categories.</a> <a data-t="818">So behind the scenes, once again, we have an R Markdown document that's pulling in the</a> <a data-t="822">data from multiple sources, making those machine learning predictions, and writing</a> <a data-t="827">this data to a database.</a> <a data-t="829">It's constantly getting updated with new applications, new awards.</a> <a data-t="833">And this is what our Shiny dashboard uses.</a> <a data-t="836">And once again, we wanted people to be able to collaborate.</a> <a data-t="840">So it's writing user inputs in a database for future use.</a></p>
