<h3>How Commons works</h3>

<p><a data-t="2180">So, how it</a> <a data-t="2189">works.</a> <a data-t="2189">So, the user, starting from the left, the user asks a question.</a> <a data-t="2189">Those can be researchers,</a> <a data-t="2196">PIs, deans, vice presidents, board members, whomever you want to have ask a question.</a> <a data-t="2203">What Commons then does is search their trusted calculations.</a> <a data-t="2203">Those trusted calculations,</a> <a data-t="2211">that semantic layer, you create in code.</a> <a data-t="2211">So, it's a, if you think about a Shiny application</a> <a data-t="2219">where you have the server UI and the app.UI, you have a document that explains exactly your</a> <a data-t="2227">trusted calculations.</a> <a data-t="2227">If a user asks a trusted calculation question, Commons will find it,</a> <a data-t="2236">run the code, and then give them the answer, along with a little check mark saying this is a verified</a> <a data-t="2243">calculation and you can trust this.</a></p>

<p><a data-t="2243">Now, in the low trust area, you've got two different</a> <a data-t="2250">possibilities.</a> <a data-t="2250">One, you have a cited calculation, which means it didn't find a calculation</a> <a data-t="2259">specifically, but in your documentation, it found a description of what a calculation might be.</a> <a data-t="2269">And in that case, it'll run the calculation for you, give you the answer, and then it will give</a> <a data-t="2274">you a cited tag.</a> <a data-t="2274">And then the last step is if it finds nothing having to do with either a trusted</a> <a data-t="2283">calculation or a citing, it'll still run a traditional AI code, but it'll give you a little</a> <a data-t="2292">note saying, hey, this is untrusted.</a> <a data-t="2292">You really need to research this before you use it for</a> <a data-t="2298">anything of interest.</a></p>

<p><a data-t="2298">So, how does it work?</a> <a data-t="2298">So, first of all, you have your client, any LLM</a> <a data-t="2346">via ellmer or chatlas if you're using Python.</a> <a data-t="2306">So, AWS Bedrock, Anthropic, Azure, GitHub Copilot,</a> <a data-t="2315">whatever LLM you want to point it to.</a> <a data-t="2315">Then you have your data sources, anything you can connect</a> <a data-t="2321">to, whether it's any kind of </a><a href="/software/dbi/">DBI</a><a data-t="2321"> connection, Databricks, Snowflake, anything you can connect</a> <a data-t="2328">to regularly using Python or R, you can connect to a commons agent.</a> <a data-t="2328">Then, as I mentioned earlier,</a> <a data-t="2336">you have your semantic layer, validated R functions or Python functions tagged with an</a> <a data-t="2341">at measure tag.</a> <a data-t="2341">This is your trusted code that you have used and have agreed upon.</a> <a data-t="2349">Then you have your context layer.</a> <a data-t="2349">This is traditionally what you would have an MCP</a> <a data-t="2355">server for, a model context protocol.</a> <a data-t="2355">And then you can also have instructions that you create</a> <a data-t="2361">as well.</a> <a data-t="2361">And then that runs through commons, and then you get your governed agent.</a></p>
