<p><a href="/software/positron/">positron</a><a data-t="0"> has a package pane for managing the packages that are installed in your</a> <a data-t="4">active R or Python sessions.</a> <a data-t="4">So you can browse installed packages, search package</a> <a data-t="9">repositories, and update or uninstall packages without ever leaving positron.</a></p>

<p><a data-t="14">The packages pane appears in the primary sidebar and you can select the icon in</a> <a data-t="19">the activity bar or you can run view packages from the command palette.</a> <a data-t="19">The packages pane lists packages installed in the active session library and so</a> <a data-t="28">each entry shows a package name, version, and whether or not the package is</a> <a data-t="33">currently attached.</a> <a data-t="33">There are also buttons to open up the packages</a> <a data-t="37">documentation in the help pane and when a package has a documentation site its</a> <a data-t="42">website in your browser.</a></p>

<p><a data-t="42">So you can use the filter input at the top of the pane</a> <a data-t="46">to search by name.</a> <a data-t="46">So for example here I can search for </a><a href="/software/ggplot2/">ggplot2</a><a data-t="46"> and see that</a> <a data-t="51">there's an update available and update it just directly from here.</a> <a data-t="51">Or if I want</a> <a data-t="56">to install patchwork in my script, I can search for patchwork and install it</a> <a data-t="60">into the active session.</a></p>

<p><a data-t="60">So all of these actions are available from the command</a> <a data-t="65">palette.</a> <a data-t="65">What you do is you type packages to see the full list, so all the commands</a> <a data-t="70">for installing, updating, uninstalling, and refreshing packages.</a> <a data-t="70">Give it a try today!</a></p>
