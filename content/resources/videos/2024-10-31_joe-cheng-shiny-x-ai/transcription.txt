<h3>Lessons learned</h3>

<p><a data-t="921">So what did we learn?</a> <a data-t="933">What did we learn from this experience,</a> <a data-t="935">from this experiment?</a> <a data-t="937">And the biggest takeaway for me was</a> <a data-t="939">the power of domain-specific languages.</a> <a data-t="942">Using SQL as this sort of intermediary</a> <a data-t="946">between the chatbot, the human, and the data app</a> <a data-t="950">worked out fantastically, because SQL</a> <a data-t="954">is pretty easy for LLMs to write these days, at least</a> <a data-t="957">the really frontier models.</a> <a data-t="959">And it's relatively easy for humans to read and reason about.</a> <a data-t="963">I mean, I don't do a lot of SQL.</a> <a data-t="965">And I write Python and R code every single day.</a> <a data-t="967">But I would rather be debugging those SQL statements</a> <a data-t="970">than debugging a bunch of pandas code,</a> <a data-t="974">or well, </a><a href="/software/dplyr/">dplyr</a><a data-t="974"> is pretty good.</a> <a data-t="976">But in general, it just constrains</a> <a data-t="979">what's possible to express in a way that makes it</a> <a data-t="982">easy to read and reason about.</a></p>

<p><a data-t="985">And it's super powerful and flexible.</a> <a data-t="987">Like, with just SQL, we were able to do all those things</a> <a data-t="989">that you saw in this demo.</a> <a data-t="993">And compared to executing straight Python or R that's</a> <a data-t="997">being written by an LLM based on a prompt</a> <a data-t="1001">from a possibly malicious user and then executed on my server,</a> <a data-t="1005">yeah, I'd rather stick to SQL.</a></p>

<p><a data-t="1008">And this experiment was using SQL.</a> <a data-t="1012">But I'm really excited to experiment further with maybe</a> <a data-t="1016">we can use Vega-Lite as a DSL for creating visualizations,</a> <a data-t="1020">or use CSS Grid as a DSL for doing different kinds</a> <a data-t="1024">of dashboard layouts.</a> <a data-t="1024">So you could ask questions in the future like,</a> <a data-t="1027">please draw me a scatterplot.</a> <a data-t="1029">And instead of getting a bunch of Python or R,</a> <a data-t="1033">you get, again, something that's easy for you</a> <a data-t="1036">to read and reason about.</a></p>
